## 12종 메타포 ↔ 4 Horsemen 패턴 매핑

LLM이 사용자의 발화를 분석한 후, 4 Horsemen 점수 분포에 따라 메타포 자동 선택:

| 메타포 | 활성화 조건 |
|---|---|
| 잠겨있는 우체통 | 담쌓기 ≥ 6 + 회복 시도 부족 |
| 끓는 주전자 | 비난 ≥ 6 + 격화 기여 ≥ 5 |
| 걸어 잠근 문 | 담쌓기 ≥ 7 + Bid 응답률 < 30% |
| 너무 큰 우산 | 방어 ≥ 5 + 조망수용 부족 |
| 비 맞는 사람 | Bid 응답률 < 20% (오래 무시당함) |
| 얼어붙은 연못 | 담쌓기 ≥ 5 + 4 Horsemen 전반 낮음 |
| 금 간 유리창 | 모든 점수 중간 + 격화 기여 ≥ 4 |
| 빈 의자 | 담쌓기 ≥ 6 + 묵힌 서운함 카테고리 |
| 넘치는 컵 | 비난 + 경멸 합 ≥ 8 |
| 흔들리는 다리 | 회복 시도 보임 + 격화 기여 중간 |
| 반쯤 열린 편지 | 회복 시도 ≥ 3 + Bid 시도 발견 |
| 뿌리 얽힌 두 나무 | 모든 점수 낮음 + Repair 자주 시도 |

매핑 알고리즘 구현: `backend/src/main/java/.../service/report/MetaphorSelector.java` (V1.5 신규)

## 공유 카드 사용 흐름

### 인스타그램 스토리 (C variant 메인)

1. 사용자가 결과 페이지에서 "공유" 버튼
2. C variant 카드 자동 노출
3. "인스타 스토리에 공유" 버튼 클릭
4. 인스타그램 앱 자동 실행, 카드가 스티커로 삽입됨
5. 사용자가 캡션 추가 후 게시
6. 친구들이 보고 "다시봄"으로 검색 또는 링크 클릭

### 카카오톡 (B variant 메인)

1. 사용자가 결과 페이지에서 "공유" 버튼
2. B variant 카드 자동 노출
3. "카톡으로 보내기" 버튼 클릭
4. 카카오톡 자동 실행, 친구 선택
5. 카드 + 다시봄 링크 자동 삽입
6. 친구가 카드 클릭 → og:image로 카드 노출 → 다시봄 진입

## 바이럴 KPI 측정

각 카드 variant별:
- 노출 수 (impression)
- 외부 도메인으로의 referrer 발생 수
- og:image 호출 수 (카카오 미리보기 = 잠재적 클릭)
- 그 카드를 본 후 가입한 사람 수 (UTM 파라미터)

## 부정 바이럴 방어 장치

### 90:10 같은 극단 비율 공유 차단

D variant (ratio bar)에서 한쪽이 80% 이상이면:
- 카드 자체에 비율 숫자 노출 X (막대만 시각적으로)
- 카드 하단 문구를 "특수한 상황의 결과로, 일반화하기 어려워요"로 자동 변경

구현: `frontend/components/result/ShareCardRatio.tsx` 내부 가드 적용됨.
