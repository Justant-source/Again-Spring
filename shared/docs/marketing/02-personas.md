# 다시봄 페르소나 (V1.5)

## 1차 타겟 (PMF 핵심)

### 김서영 (28세, 마케팅 회사 대리, 동거 2년차)

#### 인구통계
- 서울 거주, 4년제 졸업, 소득 3~4천만원
- 인스타그램·카카오톡 일상 사용
- "감정 일기" 같은 기록 앱에 호의적

#### 갈등 상황
- 남자친구와 시가 명절 분담 문제로 격주로 다툼
- 카카오톡으로 "그게 어떻게 그래?" 같은 짧은 답이 와서 더 답답
- 친구한테 하소연하면 "그건 네가 너무 예민해" 같은 답을 듣고 또 상처
- 야근 중 화장실 갔다 와서 "내가 또 뭐라고 했길래" 곱씹는 타입

#### 다시봄을 발견하는 경로
- 인스타그램 인플루언서 후기
- 카카오톡 공유 카드 (친구가 보낸 메타포 카드)
- "남편한테 서운하다" 검색 → 블로그 SEO

#### 사용 시나리오
- 싸운 직후 화장실에서 5분
- 자기 전 침대에서 5분
- 출근길 지하철에서 5분

#### 다시봄에서 얻고 싶은 가치
1. "내 감정이 정상이라는 확인" (1차 욕구)
2. "내가 뭘 진짜 원했는지 정리" (2차 욕구)
3. "상대에게 보낼 수 있는 4문장" (실용 욕구)

#### 사용 후 행동
- 메타포 카드 인스타 스토리 공유 (호기심 유발)
- 카톡 상대에게 4문장 복사 후 일부 다듬어 발송
- 며칠 후 재방문 (다른 갈등 발생 시)

## 2차 타겟 (확장)

### 박지훈 (35세, IT 회사 차장, 결혼 5년차, 자녀 1명)

#### 인구통계
- 경기 거주, 소득 5~7천만원
- 인스타그램은 가끔, 카카오톡 메인

#### 갈등 상황
- 아내와 양육관 차이 (스마트폰 노출, 학원 결정)
- 본인 부모님과의 거리감 (효도 의무감)
- 직장 스트레스로 집에서 무뚝뚝해짐

#### 다시봄을 발견하는 경로
- 1차 페르소나(김서영) 같은 사람의 입소문
- 30대 부부 블로그 SEO
- 카카오톡 알림톡 (V1.6 이후)

#### 사용 시나리오
- 출근 전 카페에서 정리
- 아내가 "다시봄 한 번 해볼래?" 권유

#### 다시봄에서 얻고 싶은 가치
1. "내가 어디서 막혀있는지 객관적 관찰"
2. "아내에게 보낼 수 있는 메시지"

## 3차 타겟 (장기)

### 이수민 (24세, 대학원생, 연인 1년차)

#### 인구통계
- 서울 거주, 학생, 인스타그램·트위터·디스코드
- MBTI에 익숙, 자기참조 콘텐츠 좋아함

#### 갈등 상황
- 남자친구와 연락 빈도, 데이트 횟수 갈등
- 친구 관계의 미묘한 거리감

#### 사용 시나리오
- 침대에서 트위터 보다가 발견
- 친구가 보낸 메타포 카드에서 진입

#### 가치
1. "내 패턴 파악 (MBTI 같은 자기참조)"
2. "메타포 카드 수집 욕구" (콘텐츠 자체)
