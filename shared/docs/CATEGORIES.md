# 대/중/소분류 카테고리 데이터

Claude Code는 이 문서를 `lib/constants/categories.ts`로 옮겨 구조화된 TypeScript 데이터로 만드세요.

---

## 데이터 구조 (TypeScript 타입)

```typescript
export interface CategoryTree {
  major: MajorCategory[];
}

export interface MajorCategory {
  id: string; // 관계 유형과 1:1 매칭
  label: string;
  relationType: RelationType;
  middles: MiddleCategory[];
}

export interface MiddleCategory {
  id: string;
  label: string;
  minors: MinorCategory[];
}

export interface MinorCategory {
  id: string;
  label: string;
  allowCustomInput: boolean; // "직접 입력" 옵션인지
}
```

## 1. 연인 / 썸

### 중분류 → 소분류

#### 1-1. 연락·관심 문제
- 연락이 너무 적어서 서운함
- 연락 강요가 부담스러움
- 답장 속도·성의 문제
- 잠수·회피 문제
- SNS 활동 관련 갈등 (좋아요, 팔로우 등)
- 직접 입력

#### 1-2. 시간·우선순위 문제
- 친구 모임을 더 우선시
- 취미·게임·운동에 시간 많이 씀
- 일·학업 때문에 시간 없음
- 가족 일정이 우선
- 데이트 시간이 적음
- 직접 입력

#### 1-3. 돈·경제 문제
- 데이트 비용 분담 문제
- 상대의 소비 습관이 불만
- 선물·이벤트 비용 갈등
- 빌려준 돈 문제
- 경제관념 차이
- 직접 입력

#### 1-4. 미래·약속 문제
- 결혼 얘기에서 의견 차이
- 동거 관련 갈등
- 진로·취업 방향 차이
- 장기 계획 없음에 대한 불안
- 약속을 자주 어김
- 직접 입력

#### 1-5. 가족·주변 관계 문제

#### 1-7. 애정 표현 방식 차이
- 스킨십 빈도·강도 차이
- 말로 표현 안 함
- 기념일 안 챙김
- 사랑 표현 방식이 달라서 서운함
- 공개적 애정 표현 차이
- 직접 입력

#### 1-8. 생활 습관 차이
- 청결·정리 기준 차이
- 수면 패턴 차이
- 식습관 차이
- 규칙적/불규칙적 생활 차이
- 시간관념 차이 (지각 등)

#### 1-9. 기념일·이벤트 문제
- 기념일 잊음
- 이벤트 준비 미흡
- 서로 기대치가 다름

## 소분류 선택 후 프롬프트 주입용

선택된 대/중/소분류는 LLM 프롬프트에 다음 형식으로 주입:

```
[CONTEXT]
관계 유형: {major.label}
갈등 카테고리: {middle.label} > {minor.label}
{커스텀 입력 시: 추가 설명: {custom_text}}
```

이 컨텍스트가 있으면 LLM이 카테고리 특화 질문을 생성할 수 있음.
