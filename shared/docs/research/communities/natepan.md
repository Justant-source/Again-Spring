## 주 이용층 (Demographics)

- **연령대**: 10대 후반 ~ 30대 초반 (중심 20대)
- **성별 비율**: 여 80%+ 
- **직종**: 학생, 직장 초년생, 주부
- **특성**: 감정 표현에 적극적, 공감 문화 강함

---

## 정치·사회 성향

- **정치 성향**: 중립 → 진보 경계 (명확한 색깔 없음)
- **성향 강도**: 온건
- **친화 이슈**: 여성 권리, 연애 자유, 개인 감정 존중
- **터부 주제**: 특정 정치인 노골적 지지, 지역 비하
- **젠더 이슈**: 페미니즘 친화적이나 급진적이진 않음

---

## 말투 특성 (Voice Profile)

**기본 톤**: 감성적, 피해자 서술형, 공감 요청

**문장 구조**: 기승전결 (상황 설명→감정 묘사→사건→의견 요청)

**줄임말/슬랭 수준**: 중간 (ㅠㅠ, ㅋㅋ, 진짜, 완전 多)

**이모티콘 사용**: 자주 (ㅠㅠ, ;;, ㅋㅋ)

**자주 쓰는 표현**:
```
"아니 진짜 황당한 일이 있었는데요..."
"솔직히 이게 맞는 건지 모르겠어서요"
"너무너무 화가 나서 여기 올려봐요"
"여러분 어떻게 생각하세요?"
"제가 이상한 건가요 ㅠㅠ"
"근데 또 이해가 되기도 하고..."
"진짜 어이없어서 기가 막히더라고요"
```

**반말/존댓말**: 자유 혼용 (같은 글에서 바꾸기도 함)

## 인기 글 유형 (실제 베스트글 패턴)

| 순위 | 갈등 유형 | 대표 제목 패턴 | 주 반응 |
|---|---|---|---|
| 1 | 연인 배신/외도 | "남자친구가 전여친이랑 연락하고 있었어요" | 분노 공감 |
| 2 | 시댁 간섭 | "시어머니가 또..." | 공감 폭발 |
| 3 | 연락 소홀 | "남친이 바쁘다고 카톡을 안 해요" | 고민 상담 |
| 4 | 직장 갑질 | "상사가 저한테만 유독..." | 분노+조언 |
| 5 | 친구 뒷담화 | "제 비밀을 친구가 다른 애한테..." | 배신감 공감 |
| 6 | 부부 가사 | "남편이 집안일을 하나도 안 해요" | 공감+분노 |

## 댓글 패턴

### 공감 많이 받는 댓글
```
"진짜 힘드셨겠다... 저도 비슷한 경험 있어요 ㅠㅠ"
"그 사람 이상한 거 맞아요. 글쓴이 잘못 없어요"
"저 같아도 화났을 것 같아요. 충분히 그럴 수 있어요"
"근데 상대방이 왜 그랬을까요? 한번 얘기해보셨어요?"
"이거 그냥 넘어가면 안 될 것 같은데요..."
```

### 비공감 받는 댓글
```
"글쓴이도 잘못 있는 것 같은데요" (논리 분석형 → 공감 0)
"그냥 참으세요" (해결 안 됨 느낌)
지나치게 중립적인 댓글
```

## 진보 vs 보수 반응 차이

| 갈등 유형 | 진보 반응 | 보수 반응 |
|---|---|---|
| 가사분담 | "가사분담은 당연한 거지" | "역할이 있지 않나요?" |
| 시댁 갈등 | "배우자가 내 편 들어야지" | "어른 공경도 중요해요" |
| 연애 자유 | "헤어지면 그만이지" | "관계는 노력이 필요해" |
| 직장 갑질 | "노동부 신고하세요" | "일 배우는 과정이잖아요" |
