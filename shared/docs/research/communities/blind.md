# 블라인드 (Blind) 성향 분석

> **URL**: https://www.teamblind.com/kr  
> **분석 날짜**: 2026-06-04  
> **신뢰도**: 높음 (KCI 논문 + 앱 분석)

---

## 기본 정보

| 항목 | 내용 |
|---|---|
| 운영 형태 | 익명 (회사 이메일 인증) |
| 회원 인증 | 재직 회사 이메일 필수 |
| 주요 주제 | 직장 생활, 연봉, 이직, 회사 문화, 상사 갈등 |
| 특징 | 인증 기반 → 내부자 신뢰도 높음 |
| 글로벌 | 한국 + 실리콘밸리 IT 직군 |

---

## 주 이용층 (Demographics)

- **연령대**: 20대 후반 ~ 40대
- **성별 비율**: 남 60% / 여 40% (추정)
- **직종**: IT/금융/대기업 직장인 중심
- **학력**: 대졸+ 비율 높음

---

## 정치·사회 성향

- **정치 성향**: 중립 (직장 이슈에 집중, 정치 색깔 약함)
- **성향 강도**: 온건~중간
- **친화 이슈**: 노동권, 연봉 투명성, 워라밸
- **터부 주제**: 특정 회사/인물 실명 비방
- **특성**: 직장 이슈에서만 의견 강해짐

---

## 말투 특성 (Voice Profile)

**기본 톤**: 분석적, 냉소적, 완곡어법 (돌려 말하기)

**문장 구조**: 상황 → 분석 → 결론 (짧고 단정적)

**줄임말/슬랭 수준**: 낮음~중간 (직장 은어 위주)

**이모티콘 사용**: 거의 없음 (전문적 이미지 유지)

**자주 쓰는 표현**:
```
"팩트만 말씀드리면..."
"이런 케이스는 보통 [원인]이더라고요"
"그냥 참거나 나오거나 둘 중 하나임"
"이직이 답임"
"저도 비슷한 상황이었는데 결국 나왔어요"
"현실적으로는..."
"그게 다 이유가 있는 거죠"
"회사가 다 그렇죠 뭐"
```

**직장 은어**:
```
칼퇴 - 정시 퇴근
갈구다 - 괴롭히다
을이다 - 약자 위치
이직각 - 이직 고려 시점
찍혔다 - 상사 눈 밖에 남
버티다 - 참고 다니다
```

## 인기 글 유형

| 순위 | 갈등 유형 | 대표 제목 패턴 | 주 반응 |
|---|---|---|---|
| 1 | 상사 갑질/폭언 | "팀장이 회의에서 공개적으로..." | 공감+이직 권유 |
| 2 | 연봉 불만 | "동기보다 연봉이 적게 나왔는데..." | 이직 권유 |
| 3 | 업무 떠넘기기 | "동료가 자꾸 제 일을..." | 공감+대처법 |
| 4 | 야근 강요 | "칼퇴하면 눈치 주는 팀장..." | 분노 공감 |
| 5 | 공로 가로채기 | "제 아이디어를 팀장이 발표에서..." | 분노+증거 수집 권유 |

## 댓글 패턴

### 공감 많이 받는 댓글
```
"이런 게 현실이죠. 저도 당해봤어요"
"그냥 이직 준비하세요. 답이 없는 데예요"
"고용노동부 1350에 신고 가능합니다 (근거법령: [X]조)"
"저도 비슷한 케이스였는데 결국 나왔어요. 잘 됐어요"
"그 회사 [회사 이름] 맞죠? 거기 유명하던데"
```

### 비공감 받는 댓글
```
"참고 견디세요" (현실성 없음)
지나치게 감정적인 댓글 (분석 커뮤니티 분위기와 안 맞음)
```

## 진보 vs 보수 반응 차이

| 갈등 유형 | 진보 반응 | 보수 반응 |
|---|---|---|
| 야근 강요 | "부당 지시 거부 권리 있음. 신고하세요" | "어느 정도는 감수해야지" |
| 상사 갑질 | "직장 내 괴롭힘 금지법 적용 가능" | "실력으로 인정받아야" |
| 연봉 불만 | "노조 결성 고려해보세요" | "이직으로 해결이 맞음" |
