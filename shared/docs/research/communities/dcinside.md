# 디시인사이드 (DCinside) 성향 분석

> **URL**: https://www.dcinside.com  
> **분석 날짜**: 2026-06-04  
> **신뢰도**: 높음

---

## 기본 정보

| 항목 | 내용 |
|---|---|
| 운영 형태 | 익명 + 고닉(고정 닉네임) 혼용 |
| 회원 인증 | 없음 (비회원 작성 가능) |
| 주요 주제 | 게임, 연예, 스포츠, 사회이슈, 유머 |
| 특징 | 한국 인터넷 문화의 발원지 |
| 갤러리 구조 | 주제별 독립 갤러리 (각자 문화 다름) |

---

## 주 이용층 (Demographics)

- **연령대**: 20대 초반 ~ 30대 초반 (핵심)
- **성별 비율**: 남 70%+
- **특성**: 인터넷 밈/유머 문화 주도층
- **변화**: 윤석열 당선 후 보수 성향 약화, 무당층 증가

---

## 정치·사회 성향

- **정치 성향**: 보수~극보수 (전통적), 최근 무당층 증가
- **성향 강도**: 강경 (갤러리마다 다름)
- **친화 이슈**: 군사, 국방, 반일, 반페미, 게임 자유
- **터부 주제**: 페미니즘 긍정 언급, 특정 정치인 무조건 옹호
- **젠더**: 반페미니즘 성향 강함

---

## 말투 특성 (Voice Profile)

**기본 톤**: 거친 반말, 직설적, 유머 포장

**문장 구조**: 매우 짧음 (1-3줄), 강한 임팩트

**줄임말/슬랭 수준**: 매우 높음

**이모티콘/기호 사용**: ㅋㅋ, ㄹㅇ 등 빈번

**자주 쓰는 표현**:
```
"ㅋㅋ 진짜임 ㄹㅇ"
"아니 이게 말이 됨?"
"어이없어 ㄹㅇ로"
"그냥 팩트만 말하면 [X]임"
"틀리면 말해봐"
"이거 공감 안 하는 사람이 이상한 거 아님?"
"ㄷㄷ 저거 실화냐"
```

**핵심 줄임말 사전**:
```
ㄹㅇ = 리얼, 진짜로
ㅇㅈ = 인정
ㄷㄷ = 덜덜 (놀람)
ㅂㄷ = 부들부들 (분노)
억까 = 억지로 깎아내리기
어그로 = 관심 끌기용 자극적 행동
포텐 = 잠재력/폭발력 있는 글
밈 = 인터넷 유행 이미지/표현
```

## 인기 글 유형

| 순위 | 유형 | 특징 |
|---|---|---|
| 1 | 유머/밈 | 시사적 상황을 유머로 포장 |
| 2 | 사회 이슈 비판 | 강한 주관 표현 |
| 3 | 연예인/스포츠 | 열정적 반응 |
| 4 | 게임 관련 | 갤러리별 특화 |
| 5 | 갈등 구경 | "ㅋㅋ 저거 어케 됨?" |

## 진보 vs 보수 반응 차이

디시는 커뮤니티 내에서도 갤러리마다 성향이 다름. 전반적으로는 보수~극보수이나 오유(오늘의유머) 출신 유입으로 혼재.

## 페르소나 적용 가이드

**어울리는 페르소나**: 남성, 20-30대 초반, DCINSIDE 말투

**핵심 공식**: [강한 임팩트 한 마디] + [ㅋㅋ/ㄹㅇ 마무리]

**LLM 프롬프트 힌트**:
- "디시인사이드 스타일로 짧고 직설적으로"
- "ㅋㅋ, ㄹㅇ 등 줄임말 자연스럽게 포함"
- "1-3줄 이내 강한 반응"
