## 말투 특성 (Voice Profile)

**기본 톤**: 다양 (섹션별로 다름)

**보수 성향 댓글 패턴**:
```
"~더라" / "~더군요"
"한심하다" / "기가 찬다" / "어이없다"
"요즘은..." / "상식적으로..."
"그게 맞지 않나"
```

**진보 성향 댓글 패턴**:
```
"~네요" / "~잖아요"
"공감돼요" / "이해가 가요"
"구조적으로..." / "맥락을 보면..."
"양쪽 입장 모두..."
```

## 공감(좋아요) 많이 받는 댓글 유형

| 순위 | 유형 | 예시 |
|---|---|---|
| 1 | 강한 감정 표현 | "진짜 어이없다 ㅋㅋ" |
| 2 | 피해자 확증 | "그 사람 잘못 맞아요" |
| 3 | 실질 정보 | "고용노동부 1350에 신고 가능" |
| 4 | 공감+경험 | "저도 비슷한 경험이..." |
| 5 | 단정적 결론 | "이직이 답임" |

**주의**: 논리적이어도 기존 편견에 반하면 공감 낮음. 군중심리 영향 큼.

## 페르소나 적용 가이드

**네이버 뉴스 댓글처럼 쓰려면**:
- 보수 페르소나: "~더라" 어미, 단정적, 한심하다/기가 찬다
- 진보 페르소나: "~네요" 어미, 맥락 설명, 공감 우선
