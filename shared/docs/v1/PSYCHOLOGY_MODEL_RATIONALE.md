# 다시봄 — 심리학 모델 채택 근거 (Rationale)

**작성일**: 2026-04-26  
**상태**: Living Document (모델 변경 시 업데이트)

## 1. 채택 기준

다시봄은 다음 3가지 원칙에 따라 심리학 모델을 채택한다.

1. **단호한 모델, 부드러운 서비스** — 내부 모델은 학술적으로 명확하되, 사용자 출력은 관찰형/가설형으로 부드럽게 전개
2. **과적합 방지** — 추적 변수는 4개로 제한 (4 Horsemen, Repair Attempt, Bid for Connection, Startup Tone)
3. **한국 적용성** — 한국 부부 대상 검증 연구가 있는 모델 우선

## 2. 채택 모델

### 2.1 Gottman Method (핵심)

- **채택 구성요소**: 4 Horsemen, Repair Attempt, Bid for Connection, Sound Relationship House (Love Maps, Fondness)
- **근거**:
  - 한국 부부 245쌍 대상 연구에서 4 Horsemen이 결혼 만족도의 60%를 설명
  - 다문화가정 한국 표본에서 SRH 모델 기반 프로그램의 효과 검증
  - 한국가족치료학회 학술지에 다수의 적용 연구 게재
- **배제 구성요소**: 이혼 예측 90~94% 주장, Gender-specific 권고
- **배제 근거**:
  - 이혼 예측: 교차검증 부재로 학계 비판 누적 (Heyman 2001 등)
  - Gender-specific: 후속 연구에서 일관되게 재현되지 않음

### 2.2 NVC (Nonviolent Communication)

- **역할**: Gottman 관찰을 사용자에게 출력할 때의 재구성 언어
- **근거**: 관찰-감정-욕구-요청 4단계 구조가 LLM 출력 형식으로 안정적

### 2.3 EFT (Emotion Focused Therapy) — 보강 레이어

- **역할**: 비난/경멸 탐지 시 "이면의 감정" 환기 한 줄 (세션당 1회 제한)
- **근거**:
  - 한국 가족치료 학계의 Gottman + EFT 통합 흐름
  - 다문화가정 EFT 적용 연구에서 효과 검증
- **제한**: 과도한 정서 환기는 사용자 부담이므로 1회 제한

## 3. 배제 모델

### 3.1 Bowen 다세대 전수 이론

- **배제 이유**: 한국 가족 구조와 잘 맞지만 평가 기간이 길고 LLM 단발 응답에 적합하지 않음. 추후 "오래 묵힌 서운함" 카테고리에 일부 반영 가능성 검토.

### 3.2 사티어 의사소통 유형

- **배제 이유**: 5가지 유형(회유, 비난, 초이성, 산만, 일치) 분류는 매력적이나, Gottman 4 Horsemen과 개념적 중복이 크고 추적 변수 추가는 과적합 우려.

### 3.3 이마고(Imago) 부부 대화법

- **배제 이유**: 미러링 기법 자체는 NVC와 통합되어 이미 반영. 별도 모델로 추가 시 출력 복잡도 증가.

## 4. 한국 고유 갈등 카테고리

Gottman은 미국 백인 중산층 표본 기반이라 다음 4가지 한국 패턴을 잡지 못한다. 별도 카테고리로 추가:

| 카테고리 | 한국적 맥락 |
|---|---|
| in_law (시댁/처가) | 한국 이혼 통계 "가족 간 불화" 7.4% 별도 사유, 직계존속 폭력은 재판상 이혼 사유 |
| face (체면) | 이성범(2014) "체면과 권리의 관점에서 본 부부 대화의 불통" 등 학술 연구 |
| lingered (묵힌 서운함) | 김지영(2005) "스트레스, 부정적 기분 조절 기대치, 화병" 등 연구 |
| generation (세대차) | 이두원(2009) "부부간 의사소통 행태의 세대별 특성과 변천과정" 등 연구 |
