## 일일 운영 절차

1. `/admin/marketing` 대시보드에서 이달 비용 확인 (월 $20 한도)
2. 새 사연 수집 → `/admin/marketing/stories/new` 등록
3. 익명화 결과 검토 → 재작성률 50%+ 확인 → 승인
4. 시뮬레이션 시작 → 1~3분 대기 → 완료 확인
5. 3개 플랫폼 콘텐츠 생성 → 안전 검사 통과 확인
6. 필요 시 내용 편집 → 승인
7. 발행 전 최종 검토 → 수동 발행

## 비용 알림

- 월 예산 80% 도달 시 서버 로그(WARN)에 기록됨
- 로그 확인: `docker logs againspring-backend-dev | grep "마케팅 월 예산"`

## 장애 대응

| 증상 | 원인 | 조치 |
|---|---|---|
| 시뮬레이션 FAILED | LLM 타임아웃 또는 오류 | 사연 재승인 후 재시도 |
| 익명화 실패 | LLM 연결 오류 | LLM 워커 상태 확인 후 재등록 |
| 이미지 렌더링 실패 | marketing-renderer 미기동 | `docker compose up marketing-renderer-dev` |
| 일일 한도 초과 | 10건/일 도달 | 다음 날 자정(UTC) 초기화 |
