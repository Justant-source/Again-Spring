## 🆕 은유 카드 3장 설계

### 카드 컨셉

각 카드는 **자연·계절·식물 모티프**로 두 사람의 관계를 은유적으로 묘사. MBTI 결과 카드와 비슷한 톤.

### 카드 1: "두 분의 욕구"

**제목 예시**:
- "물과 바위처럼 다른 두 마음"
- "각자의 봄을 향한 두 갈래 길"

**구성**:
- 일러스트: 두 자연물 (예: 물과 바위, 꽃과 나무)
- 본문: 4-5줄
  - A의 욕구 1줄 ("[A]님은 함께 있는 시간에서 안정감을 느끼시고")
  - B의 욕구 1줄 ("[B]님은 혼자만의 시간에서 회복하시는 분이에요")
  - 종합 1줄 ("두 분 모두 관계를 소중히 여기는 마음에서 나온 거예요")
- 강조 색상: 봄 라벤더(#B4A6E3)

**LLM 프롬프트 예시**:
```
두 사람의 욕구 차이를 자연 은유로 묘사하세요.
- 형식: 제목 + 4-5줄 본문
- 비교/판단 없이, 양쪽 모두를 긍정적으로 묘사
- "욕구"라는 단어 대신 "원하시는 것", "필요한 것" 등 일상어 사용
- 임상 용어 금지
```

### 카드 2: "함께 자라는 길"

**제목 예시**:
- "서로 다른 계절을 인정하는 법"
- "두 마음이 만나는 작은 길"

**구성**:
- 일러스트: 길, 다리, 만나는 두 식물
- 본문:
  - "이번 갈등의 핵심은..." (1-2줄, 핵심 갈등 요약)
  - "두 분 사이의 거리는..." (1줄, 욕구 거리 5단계 라벨)
  - "관계가 자라기 위해서는..." (1-2줄, 행동 방향)
- 강조 색상: 봄 연두(#7FB77E)

### 카드 3: "다음 한 걸음"

**제목 예시**:
- "오늘 저녁, 시작할 수 있는 작은 것"
- "한 마디로 시작되는 회복"

**구성**:
- 일러스트: 작은 새싹, 발걸음
- 본문:
  - 구체적 행동 1개 ("오늘 저녁 7시, 다음 문장 한 줄을 보내보세요")
  - 예시 문장 (인용구 형식)
  - 추가 안내 1줄
- 강조 색상: 봄 분홍(#F4C0D1)

## 💰 화해 기여도 재설계

### UI 구조

```
┌────────────────────────────────────────────┐
│ 🤝 화해 기여도                              │
│                                            │
│ ████████████████░░░░░░░░ A 60% : B 40%    │
│                                            │
│ A님 → "먼저 다가가면 좋은 쪽"              │
│ B님 → "마음 열고 기다려주면 좋은 쪽"        │
│                                            │
│ ┌──────────────────────────────────────┐  │
│ │ 💡 안내                              │  │
│ │ 이 수치는 두 분의 회복 시작점을      │  │
│ │ 부드럽게 안내하기 위한 참고용이에요.  │  │
│ │                                      │  │
│ │ 법적 판단·과실비율과는 무관하며,      │  │
│ │ AI 분석에는 한계가 있어요.           │  │
│ │                                      │  │
│ │ 깊은 갈등은 전문 상담을 권해드려요.  │  │
│ └──────────────────────────────────────┘  │
└────────────────────────────────────────────┘
```

### 시각 요소

- **막대 그래프**: A는 봄 라벤더(#B4A6E3), B는 봄 분홍(#F4C0D1)
- **숫자**: 큰 글씨(24px) but 강압적이지 않게
- **라벨**: 양쪽 모두 긍정 표현
- **안내 박스**: 옅은 회색 배경 + 작은 글씨(12-13px) but 확실히 보이게

### 표시 규칙

| 갈등 유형 | 비율 범위 | 안내문구 |
|---|---|---|
| 사실형 (factual) | 80:20 ~ 100:0 | 기본 안내 + "이번 상황에서는 한쪽의 책임이 좀 더 분명해 보여요" |
| 차이형 (difference) | 50:50 ~ 70:30 (강제 클립) | 기본 안내 + "두 분 모두 잘못한 게 아니라 다를 뿐이에요" |
| 혼합형 (mixed) | 50:50 ~ 85:15 | 기본 안내 |

└────────────────────────────────────────────┘

### 거리 계산 로직

```typescript
// lib/utils/needsMapDistance.ts
export function calculateDistanceLabel(
  positionA: { x: number; y: number },
  positionB: { x: number; y: number }
): { level: 1 | 2 | 3 | 4 | 5; label: string; emoji: string } {
  const distance = Math.sqrt(
    Math.pow(positionA.x - positionB.x, 2) + 
    Math.pow(positionA.y - positionB.y, 2)
  );
  
  // 좌표 범위: -100 ~ +100, 최대 거리 = sqrt(200^2 + 200^2) ≈ 282
  if (distance < 50)  return { level: 1, label: '매우 가까움', emoji: '💚' };
  if (distance < 100) return { level: 2, label: '가까움', emoji: '🌱' };
  if (distance < 150) return { level: 3, label: '적당히 떨어짐', emoji: '🟡' };
  if (distance < 200) return { level: 4, label: '떨어짐', emoji: '🟠' };
  return { level: 5, label: '많이 떨어짐', emoji: '🔴' };
}
```

### 메타포 카드 생성 프롬프트

```markdown
# 메타포 카드 생성 가이드

세 장의 카드를 자연·계절·식물 은유로 작성하세요.

## 카드 1: "두 분의 욕구"
- 두 사람의 욕구 차이를 자연 은유로 묘사
- 비교/판단 없이 양쪽 모두 긍정적으로
- "욕구"라는 단어 대신 "원하시는 것", "필요한 것" 사용

## 카드 2: "함께 자라는 길"
- 갈등의 핵심을 한 줄로 요약 (구체적 사실 X, 관계 패턴 O)
- 두 분의 거리감을 5단계 라벨로 표현
- 관계가 자라기 위한 방향 제시

## 카드 3: "다음 한 걸음"
- 구체적이고 실행 가능한 행동 1개
- 시간/장소/대사를 포함한 마이크로 액션
- 부담스럽지 않은 작은 시작

## 톤
- 따뜻하고 차분한 존댓말
- 봄 모티프 활용
- 임상 용어·진단 표현 금지
```

## 🧪 검증 시나리오

### 시나리오 1: 차이형 갈등 결과 표시
```
입력: A "연락이 너무 적어요" / B "혼자 시간이 필요해요"

기대 결과:
✅ 욕구 차이 지도 표시 (거리: 떨어짐 4/5)
✅ 메타포 카드 3장 표시
   - 카드 1: "물과 바위처럼 다른 두 마음"
   - 카드 2: "각자의 봄을 인정하는 법"
   - 카드 3: "오늘 저녁 7시, 한 문장 보내기"
✅ 화해 기여도 55:45 + 안내문구 박스
✅ NVC A→B, B→A
✅ Repair 3개
❌ 관계 온도 표시 없음
❌ Four Horsemen 섹션 없음
```

### 시나리오 2: 사실형 갈등
```
입력: A "약속을 3번 연속 어겼어요" / B "회사 일이 바빴어요"

기대:
✅ 화해 기여도 75:25 (사실형이므로 70:30 클립 적용 안 함)
✅ 안내문구 +"이번 상황에서는 한쪽 책임이 좀 더 분명해 보여요"
✅ B에게 보낼 NVC가 더 진중한 톤
```

### 시나리오 3: Power Imbalance
```
입력: "그가 자꾸 통제하려고 해요. 나가지도 못하게 해요."

기대:
✅ Crisis Resource 모달 즉시 표시
✅ 결과 생성 진행 중단 또는
✅ 결과 표시 시 화해 기여도 섹션 비표시
✅ 대신 전문기관 연락처 강조
✅ DB에 power_imbalance_detected = true 기록
```

### 시나리오 4: Solo 모드
```
입력: A만 한 줄 입력

기대:
✅ 욕구 차이 지도 (B 위치 흐릿한 점선 원)
✅ 메타포 카드 3장 (Solo 버전)
✅ 화해 기여도 placeholder (CTA: "상대방 초대")
✅ NVC A→B만
✅ Repair 1-2개
✅ 워터마크 "Solo 분석"
```
