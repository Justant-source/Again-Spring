# 금지어 정책

UI · 코드 · 프롬프트 · LLM 출력 모두에서 다음 단어 사용 금지. 4단계로 분류.

## Source of truth

- FE: `frontend/lib/constants/forbiddenWords.ts`, `frontend/scripts/check-forbidden-words.js`
- BE: `backend/src/main/resources/safety/forbidden-words.yml`, `backend/.../safety/KeywordGuard.java`

코드와 다르면 코드가 옳습니다 — 문서를 갱신하세요.

## 검증

```bash
cd frontend && npm run lint:words   # 하드코딩된 금지어 스캔, 위반 시 exit 1
```

BE는 `KeywordGuard`가 사용자 입력 단계에서 자동 검사 + LLM 응답 후처리에서도 재검사.

## Level 1 — 법률 용어 (변호사법 저촉 우려)

| 금지어 | 대체어 |
|---|---|
| 과실비율 | 화해 기여도 |
| 판결 | 결과 / 분석 |
| 판사 | 중재자 |
| 유죄 | (사용 금지) |
| 무죄 | (사용 금지) |
| 가해자 | (사용 금지, 낙인) |
| 피해자 | (사용 금지, 낙인) |
| 고소 | (사용 금지) |
| 소송 | (사용 금지) |
| 증거 | 입력 / 말씀 |
| 심판 | 중재 |

## Level 2 — 임상·병리 용어

진단명·임상 라벨은 의료법 저촉 + 악용 가능 + 낙인 위험.

| 금지어 | 비고 |
|---|---|
| 나르시시스트 | 진단명 |
| 소시오패스 | 진단명 |
| 가스라이팅 | 악용 가능 용어 |
| 회피성 / 경계성 성격 | 임상 용어 |
| 공의존 | 임상 용어 |
| 트라우마 / PTSD | 임상 용어 |
| ADHD / 자폐 | 임상 용어 |
| 우울증 / 조울증 | 진단명 |
| 회피형 / 불안형 (애착) | 애착이론 자체 제거 |

**대체 원칙**: 진단·인격이 아니라 **구체적 행동**으로 기술.

| 진단 | 행동 기술로 대체 |
|---|---|
| "회피형이시네요" | "대화 중 거리를 두고 싶어하시는 편이군요" |
| "가스라이팅이에요" | "상대의 표현이 자주 흔들리는 것처럼 들리실 수 있어요" |

## Level 3 — 판결·승패 용어

관계는 누가 이기고 지는 게임이 아님.

| 금지어 | 대체어 |
|---|---|
| 이겼다 / 졌다 | (사용 금지) |
| 승자 / 패자 | (사용 금지) |
| 맞다 / 틀렸다 | 다르다 / 각자의 관점 |
| A가 잘못했다 | A님의 이 부분이 아쉬웠어요 |
| 정답 / 오답 | (사용 금지) |

## Level 4 — 관계 파국 조장

관계 결정(헤어짐 등)은 서비스 범위 외.

| 금지어 | 이유 |
|---|---|
| 헤어지세요 / 이혼 추천 | 관계 결정은 사용자의 몫 |
| 절교 / 손절 / 인연 끊기 | 관계 파국 조장 |
| "이런 사람 만나지 마세요" | 낙인·판단 |

## §5 1차 조언 시 회피 표현 매핑 (V1.5 신규)

> 본 §5는 **LLM 응답 텍스트 전용**입니다. UI 카피·코드 변수명에는 적용되지 않습니다 (Level 1~4 기준 적용).

### 5.1 단정적 권고 → 권유형으로

| 회피 표현 (금지) | 권장 표현 |
|---|---|
| "이혼하셔야 해요" | "이혼을 고민하시는 마음이 있으시다면, 변호사 상담을 함께 받아보시는 게 좋아요" |
| "변호사 선임하세요" | "변호사 상담을 함께 받아보시는 것도 방법이에요" |
| "정신과 가셔야 해요" | "정신건강의학과 상담이 함께 필요할 수 있어요" |
| "약 처방 받으세요" | "약물 도움이 필요할지는 의사가 판단할 수 있어요" |
| "이렇게 하세요" | "이렇게 하는 방법이 있어요" |
| "퇴사하세요" | "상담 통해 옵션을 먼저 확인해보시는 것도 방법이에요" |

### 5.2 구체 수치·법조항·약물명 → 추상 안내로

| 회피 표현 (금지) | 권장 표현 |
|---|---|
| "민법 ○○○조에 따르면..." | "법적으로 어떻게 해석되는지는 변호사 상담이 정확해요" |
| "6억의 30%면 1.8억 청구 가능..." | "구체적인 액수는 변호사·세무사 상담이 필요해요" |
| 약물 이름 (프로작, 렉사프로, 자낙스 등) | 약물명 일체 금지 |
| "우울증입니다", "공황장애세요" | "이런 마음이 일주일 이상 이어지시면..." 가설형 |

### 5.3 조언 회피 패턴 → 옵션 펼치기로 (★ 핵심)

사용자가 명시적으로 조언을 구할 때("어떻게 해야 할까?" 등) 다음 응답은 **금지**:

| 회피 표현 (금지) | 권장 표현 |
|---|---|
| "혹시 가장 중요한 게 뭔지 한번 생각해보셨어요?" | "지금 떠오르는 방법 몇 가지 있어요. 첫째, [옵션 A]. 둘째, [옵션 B]. 셋째, [옵션 C]. 어느 쪽이 마음에 와닿으세요?" |
| "어떤 결정을 내리고 싶으세요?" | (위와 동일 — 옵션 펼치기) |
| "지금 마음의 정리가 더 필요한 시점인 것 같아요." | (위와 동일 — 옵션 펼치기) |
| "그 마음 안에 답이 있을 것 같아요." | (위와 동일 — 옵션 펼치기) |
| "지금 가장 마음에 드는 방향이 어떤 건가요?" | (위와 동일 — 옵션 펼치기) |

**예외**: 묵시적 조언 요청 시 동의 구하기는 허용:
> ✅ "혹시 지금 떠오르는 방법 몇 가지 말씀드려도 될까요?" (LLM이 묵시적 요청을 감지하고 동의 구할 때)

### 5.4 외부 자원 안내 시 누락 금지 표현

법적·세무·의료·재정·학교·직장·종교 영역에서 1차 조언을 제시할 때, 다음 한 줄은 **반드시 포함**:

> "저는 그 과정에서 마음이 무너지지 않도록 옆에 있을게요."
> (또는 동등 표현: "저는 그 과정의 마음을 함께 정리해드릴게요.")

이 마지막 한 줄이 다시봄을 단순 검색 도구·법률 챗봇과 구별짓는 정체성입니다. 누락하면 도구가 떠넘기는 인상을 주게 됩니다.

자세한 영역별 자원 매핑: [external-resources.md](./external-resources.md)

```javascript
const FORBIDDEN = [
  '과실비율','판결','판사','유죄','무죄',
  '가해자','피해자','승자','패자',
  '나르시시스트','소시오패스','가스라이팅',
  '손절','절교','절연',
];
const ALLOWED_CONTEXTS = ['판결이 아니라', '판결·승패']; // 사전 승인된 안내 문맥

```

## BE 측 일치 (`KeywordGuard`)

`backend/src/main/java/com/againspring/safety/KeywordGuard.java`가 동일 단어 목록을 `safety/forbidden-words.yml`에서 로드하여:

1. 사용자 입력에 포함 시 → `BusinessException(FORBIDDEN_WORD_DETECTED)`
2. LLM 응답에 포함 시 → 응답 차단 + `FallbackResponses` 반환

FE의 `forbiddenWords.ts`와 BE의 `forbidden-words.yml`이 어긋나면 BE가 마지막 게이트 — 변경 시 양쪽 동시 갱신 필요.
