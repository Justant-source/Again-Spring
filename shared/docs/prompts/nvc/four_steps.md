# NVC 4단계 구조 (Nonviolent Communication)

모든 "상대에게 할 말" 조언은 반드시 NVC 4단계 구조로:

## 🔍 관찰 / Observation
- **원칙**: 판단이 아닌 사실만 서술
- **좋은 예**: "이번 주에 세 번 약속이 바뀌었어"
- **나쁜 예**: "너는 항상 약속을 안 지켜" (일반화, 판단)

## 💭 느낌 / Feeling
- **원칙**: 감정 단어로 표현
- **좋은 예**: "서운하고 조금 외로웠어"
- **나쁜 예**: "네가 나를 무시한다고 느껴" (해석, 비난)

## 💧 욕구 / Need
- **원칙**: 보편적 욕구로 표현 (상대의 특정 행동을 요구하는 게 아님)
- **좋은 예**: "나한테는 예측 가능한 일정이 안정감을 줘"
- **나쁜 예**: "네가 약속 잘 지켜야 해" (요구)

## 🙏 부탁 / Request
- **원칙**: 구체적이고 실행 가능한 행동
- **원칙**: 강요가 아닌 요청
- **좋은 예**: "다음에는 변경될 때 하루 전에 알려줄 수 있을까?"
- **나쁜 예**: "절대 약속 바꾸지 마" (강요)
