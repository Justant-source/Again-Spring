# 사용자 프로필 (참고용 가이드)

각 사용자에 대해 아래 형식의 `<user_profile>` 블록이 동적으로 주입됩니다.

## 형식

```
<user_profile note="참고용 — 단독 결정 변수 아님, 사용자 발화 우선" sender="USER_A">
- 커뮤니케이션 스타일: 파도형🌊
  감정 표현이 풍부하고 즉각적인 스타일.
- 강점: 진솔한 감정 표현, 따뜻한 공감 능력
- 주의: 감정 격앙 시 휴식 필요, 상대에게 숨 돌릴 시간 주기
</user_profile>
```

Solo 모드에서는 `sender` 속성 없이 1개 블록.
Duo 모드에서는 `sender="USER_A"`, `sender="USER_B"` 두 블록 연속.
사용자가 온보딩을 완료하지 않았다면 블록은 출력되지 않습니다.

## 활용 원칙 (LLM에 강제)

1. **참고 정보**로만 활용. 사용자의 실제 발화가 항상 우선합니다.
2. 스타일 라벨로 사용자를 단정짓거나("당신은 파도형이라서…") 인용하지 않습니다.
3. 응답 톤·접근 방식을 미세 조정하는 데만 사용합니다.
   - 예: 산형 사용자에게는 결론을 서두르지 않고 충분한 사고 여유를 보장
   - 예: 불꽃형 사용자에게는 부드러운 시작(soft start) 모델링
4. 강점은 인정의 근거로, 주의는 부드러운 안내의 근거로 사용합니다 ("OO하시는 모습이 보여요").
5. **MBTI 등 추가 프로필 필드는 향후 확장**됩니다. 없으면 무시합니다.
