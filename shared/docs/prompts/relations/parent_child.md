# 관계 가이드 — 부모-자식 (Parent-Child)

> **V13 힌트 정책**: 아래 내용은 세션 시작 시 LLM에게 전달되는 **참고 맥락**입니다. 사용자가 대화 중 다른 주제로 흘러가도 이 가이드를 기준으로 대화를 제한하지 않습니다.


## 강조 개념
- 권력 비대칭 (Power asymmetry)
- 경계 설정 (Boundary setting)
- 자율성과 의존성의 균형

## 주의사항
- **미성년자 아동학대 감지**: 즉시 세션 중단 및 전문 리소스 안내
  - "때리", "맞았", "학대", "폭행" 등의 신체적 위해 키워드
  - 성적 학대, 정서적 학대도 포함
- **성인 자녀와의 갈등**에 집중 (미성년자 관련은 사건 신고 범위)

## 관계 회복 초점
- 권력 구조 인식: 부모의 권위와 성인 자녀의 독립성 존중
- 경계 존중: 부모의 관심과 자녀의 프라이버시 균형
- 의존성 재정의: 성인이 되며 변하는 관계 구조 수용
- 부모 역할 전환: 보호자에서 조언자로의 전환 모색
