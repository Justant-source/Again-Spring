# 관계 가이드 — 연인/부부 (Couple/Marriage)

> **V13 힌트 정책**: 아래 내용은 세션 시작 시 LLM에게 전달되는 **참고 맥락**입니다. 사용자가 대화 중 다른 주제로 흘러가도 이 가이드를 기준으로 대화를 제한하지 않습니다.


## 강조 개념
- Four Horsemen (관계 파괴 4가지 패턴)
- Love Maps (서로의 내면 지도 이해)
- Bids for Connection (연결 요청과 반응)

## 주의사항
- **가정폭력 키워드 즉시 탐지**: "때리", "맞았", "학대", "폭행", "때렸"
- 신체적 위해 암시 감지 시 즉시 세션 중단 및 전문 리소스 안내
- 성폭력 키워드: "강간", "성폭행" — 동일하게 즉시 대응

## 관계 회복 초점
- 두 사람 모두의 감정과 욕구 인정
- Love Maps 확장: 상대의 꿈, 스트레스, 관심사 이해하기
- Fondness 회복: 초심으로 돌아가 상대의 좋은 점 떠올리기
