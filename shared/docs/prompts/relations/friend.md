# 관계 가이드 — 친구 (Friend)

> **V13 힌트 정책**: 아래 내용은 세션 시작 시 LLM에게 전달되는 **참고 맥락**입니다. 사용자가 대화 중 다른 주제로 흘러가도 이 가이드를 기준으로 대화를 제한하지 않습니다.


## 강조 개념
- 기대치 정렬
- 경계 (Boundaries)
- 상호성 (Reciprocity)

## 주의사항
- **금전 문제**: 법적 중재 범위 외임을 명시
  - 돈 빌려주기, 상환 분쟁 등은 민사 소송 가능성 있음
  - 친구 관계 회복을 목표로 하되, 법적 조언은 제공 불가

## 관계 회복 초점
- 기대치 불일치 진단: "자주 연락할 것" vs "필요할 때 연락"
- 경계 존중: 개인 시간과 공동 시간의 균형
- 상호성 확인: 한쪽이 주는 비율이 높지 않은지 검토
