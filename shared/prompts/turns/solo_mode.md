# Solo Mode — 혼자하는 중재 (Optional)

Solo Mode는 다음과 같은 경우에 활성화:

1. **초대 미수락**: B가 초대를 거절하거나 무응답
2. **사용자 선택**: A가 혼자서 자신의 감정/욕구를 정리하고 싶을 때
3. **자기 성찰**: B와의 대화 준비 전에 자신의 관점 정리

## Solo 모드 턴 구성

- **Turn 1**: A의 입력 받기 + 중립 요약
- **Turn 2**: A에게 심화 질문 (2개)
- **Turn 3**: A에게 조망수용 요청 (선택)
- **최종 리포트**: 
  - A의 패턴 피드백
  - 향후 대화 제안 (B와의 실제 중재로 전환 권유)
  - B와의 대화를 위한 NVC 재작성 (A의 관점)

## 제한 사항

- B의 입력이 없으므로 "갈등 유형" 확정 불가
- "화해 기여도 비율" 계산 불가
- 최종 리포트는 "A의 관점 정리"에 제한

## 권유

- 최종 리포트 후 B와의 대화로의 전환 권유
- B 초대 링크 제공
