## 분류 방식 (키워드 기반)

### 알고리즘

1. **키워드 시드 매칭** (토큰 0):
   - **COUPLE**: 남친, 여친, 남자친구, 여자친구, 연인, 사귀, 데이트, 썸, 전남친, 전여친, 배우자 등
   - **MARRIED**: 남편, 아내, 와이프, 신랑, 부부, 시어머니, 시댁, 처가, 이혼, 결혼생활 등
   - **FRIEND**: 친구, 절친, 베프, 동창, 같은 반, 학교, 단짝 등
   - **FAMILY**: 엄마, 아빠, 어머니, 아버지, 동생, 언니, 오빠, 형, 누나, 부모님, 할머니, 할아버지 등
   - **WORK**: 회사, 직장, 팀장, 부장, 상사, 동료, 직원, 사장, 야근, 업무, 퇴근, 직장인, 사원 등
   - **OTHER**: 위 키워드 없음

2. **로브 가중 (lovetalk 소스)**:
   - `source` 필드에 `lovetalk` 포함 → **자동 COUPLE** (신뢰도 0.95)

3. **신뢰도 계산**:
   - 각 광장별 키워드 스코어를 정규화 (0~1)
   - 최고 점수 광장으로 배정
   - 저신뢰(no keywords) → OTHER로 폴백

- **도구**: Python 3 (keyword regex + docker exec mariadb)
- **스크립트**: `/home/justant/Data/Again-Spring-AI-User/scripts/classify_natepan_plaza.py`

## DB 적재 검증

### 적재 상태

```sql
-- NATEPAN 중 plaza 태그가 적재된 행
SELECT COUNT(*), SUBSTRING_INDEX(source, '|', -1) as plaza 
FROM corpus_item 
WHERE community = 'NATEPAN' AND source LIKE '%plaza:%' 
GROUP BY plaza;
```

**결과**:
```
307  plaza:COUPLE
555  plaza:FAMILY
217  plaza:FRIEND
466  plaza:MARRIED
2192 plaza:OTHER
1125 plaza:WORK
-----
5,662 (재확인 필요 — 예상 5,093과 차이)
```

> **주의**: 건수 차이가 있을 수 있음 (스크립트 재실행 또는 DB 상태 변경)
