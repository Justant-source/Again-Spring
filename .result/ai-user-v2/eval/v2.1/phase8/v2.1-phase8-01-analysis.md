| 평가자 | ID | AI 식별률 | Human 오탐 |
|---|---|---|---|
| 최일찬 | E-004 | 40% (Q2·Q10) | 1건 (Q3) |
| 김태준/태추 | E-005 | 0% | 4건 (Q3·5·6·8) |

> **잠정성**: 4인 = 게이트 충족(≥3)이나 추가 응답 예정. 최종 봉인 보류.

## 2. 강건성 — 추가 평가자에 PASS가 얼마나 버티나

현재 {40,0,0,40} 평균 20%. 신규 평가자 점수 추가 시:

| 시나리오 | 풀 평균 | 판정 |
|---|---|---|
| +1 @ 100% | 180/5 = 36% | PASS |
| +3 @ 100% | 380/7 = 54.3% | PASS |
| +4 @ 100% | 480/8 = 60% | PASS (경계) |
| **+5 @ 100%** | 580/9 = 64.4% | **FAIL** |

**최악(100% 만점 적발자)이 5명 연속 들어와야 FAIL로 뒤집힘.** 평범한 신규(~50%)면 +8명도 안전. PASS는 강건.

## 3. 평가자 판별력 — 사실상 구별 불가 (강한 PASS 신호)

- **AI 식별률 20%** vs **Human 오탐률 55%(11/20)** → **역전**. 진짜 사람을 AI로 더 자주 오인.
- **Q3(천주교의민단, 실제 사람) = 4/4 만장일치 AI 오판** (확신 50~100%). 평가자의 "AI 탐지 직감"이 진짜 사람에게 오발동.
- **신뢰도 보정 실패**:
  - 김윤태 = 확신 ~100%인데 AI 식별 0% → **확신에 찬 오답** (Phase 5 E-001 과신 패턴 반복).
  - 김태준 = 전 문항 확신 50% → **순수 추측**(신호 0).
- **해석**: AI 글과 사람 글이 이 평가자들에게 **통계적으로 구별 불가**. 캐주얼 독자 타깃 충족의 직접 증거.

## 5. named-tell 이동 — Phase 6 효과 (정성, 시사적)

Phase 5 강신호 → Phase 8 총평 언급:

| Phase 5 Tell | Phase 8 언급 | 해석 |
|---|---|---|
| T1 동일사건반복 | ❌ 0건 | 소멸 또는 폐색 |
| T3 광장불일치 | ❌ 0건 | 소멸 또는 폐색 |
| T2 미완종결 | ⚠️ 묵시("문장나열") | 상위신호로 재표현 |
| T4 종결단조 | ⚠️ 묵시("슬랭부재") | 상위신호로 재표현 |

**신규 Phase 8 tell 후보** (총평 4건 기반):
- **T5 어휘이질감** — 희귀·이상한 단어 삽입 (최일찬·윤도현)
- **T6 과교정문법** — 문법이 지나치게 완벽 (김태준)
- **T7 슬랭부재** — ㄹㅇ·ㅋㅋㅋ·줄임말 없음 (김윤태)
- **T8 문장비응집** — 앞뒤 단절·나열식 (윤도현)

**판정**: 4명 누구도 "반복(T1)·주제 안 맞음(T3)"을 언급하지 않음 → Phase 6 다양화 + Phase 4 광장정렬이 **T1·T3를 주신호 자리에서 밀어냈을 가능성 높음**. 단 "언급 부재 ≠ 완전 제거" — 정량 미검증.

**다음 라운드 가능성**: T5·T6·T7은 결정론 조정(PromptAssembler 띄어쓰기 오류 허용·슬랭 주입, OutputSanitizer 어휘)으로 접근 가능. T8(응집)은 의미수준 → QLoRA 영역. **단 이미 20% PASS라 추가 라운드는 선택사항.**

## 6. 과학적 엄밀성 — 과대해석 방지 ⚠️

**Phase 5(80%) → Phase 8(20%), −60pp.** 그러나 동시에 변한 변수 5개:

| 변수 | Phase 5 | Phase 8 |
|---|---|---|
| 생성 코드 (의도된 처치) | Phase 4 | Phase 6 |
| AI 계정 | 024·065 등 | 043·057·035·060·032 |
| 평가자 | E-001~003 | E-004~007 (겹침 0) |
| 배치 순서 | H-A-A-… | A-A-H-… |
| Human 비교 계정 | Phase 5 셋 | Phase 8 셋 |

- **게이트 PASS는 유효**: kill criterion은 **절대 임계**(평균 ≤60%)이지 Phase5 대비 델타가 아님. Phase 8 키트 자체가 20% = 독립적으로 PASS.
- **"Phase 6이 개선을 일으켰다"는 인과 주장은 시사적(SUGGESTIVE)**: 5개 변수 동시 변화로 코드 기여만 분리 불가. R3/R5(1변수/측정) 위반.
- **정직한 프레이밍**: 출하 게이트 = PASS(절대). 메커니즘 = "Phase 6 기여 시사, 미증명". 깨끗한 인과 증명은 동일 키트·코드만 변경 재측정 필요(이번 라운드엔 불가, v3 과제).
