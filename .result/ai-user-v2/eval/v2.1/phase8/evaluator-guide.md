```

각 게시글 묶음이 실제 사람이 쓴 것인지, 아니면 컴퓨터가 자동으로 만든 것인지 직관적으로 판단해 주시면 됩니다.

소요 시간: 약 15~20분
```

## 결과 수집

평가가 끝나면 화면 하단에 **결과 텍스트**가 자동 생성됩니다. 평가자는:

1. **"결과 전체 복사"** 버튼을 누름 (모바일은 **"공유하기"** 버튼으로 카톡에 바로 전송 가능)
2. 복사된 텍스트를 **오너에게 카카오톡·문자·메일 중 편한 방법으로 전달**
3. 자동 복사가 막힌 환경에서는 회색 칸을 **길게 눌러 전체 선택 → 복사** (HTML에 안내 문구 표시됨)

> 💾 입력은 자동 저장되어, 평가자가 중간에 창을 닫거나 새로고침해도 다시 열면 이어서 작성할 수 있습니다.

결과 형식 예시:

    === 다시봄 블라인드 평가 결과 ===
    평가자: [이름]
    일시: 2026-06-2X HH:MM
    키트: v2.1-Phase8-01
    ================================
    문제 1: 봇  (자신감 80%)
    문제 2: 사람  (자신감 60%)
    ...
    봇 판정 개수: N/10
    사람 판정 개수: M/10
