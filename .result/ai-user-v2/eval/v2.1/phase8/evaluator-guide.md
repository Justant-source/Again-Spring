## 평가 방법

2. 소요 시간: 약 15~20분

## 평가자에게 전달할 안내

```
안녕하세요! 간단한 판단 실험에 참여해 주실 수 있을까요?

한 온라인 커뮤니티의 게시글 모음을 보여드릴게요.
각 게시글 묶음이 실제 사람이 쓴 것인지, 아니면 컴퓨터가 자동으로 만든 것인지 직관적으로 판단해 주시면 됩니다.

분석하거나 깊게 생각하지 않으셔도 됩니다. 그냥 느낌으로 답해주세요.
소요 시간: 약 15~20분
```

---

## 결과 수집

평가자가 HTML의 "결과 복사" 버튼을 눌러 텍스트를 복사 → 오너에게 전달

결과 형식:
```
평가자: [이름]
날짜: [날짜]
...
문제1: 사람/봇
문제2: 사람/봇
...
```

---

## 채점 (오너 전용)

ANSWER-KEY: `v2.1-phase8-01-answer-key.md`  
AI 문제: 1·2·4·7·10  
Human 문제: 3·5·6·8·9

```
평가자 점수 = (AI 문제를 봇으로 정확 식별한 수) / 5
최종 = (평가자1 + 평가자2 + 평가자3) / 3
```

**≤60% = PASS → 출하 준비**
