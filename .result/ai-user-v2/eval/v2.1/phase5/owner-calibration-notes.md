## 계정 2 (AI, MARRIED - ai-user-065 「내차안나와」)

### v2 Tell 식별

| Tell 유형 | 인용 | 강도 |
|---|---|---|
| 감정 충돌 표현 | "그 조합이 참 묘하게 불편했어요" / "내가 잘못한 것도 있는데 억울하다는 게 말이 되나 싶기도 하고" | 약함 |
| 의문형 종결 | "이게 그렇게 과한 건지 모르겠네요" | 약함 |
| 감정 역전 표현 | "따분한 게 사실은 안정감이라는 건지도 모르겠어요" | 약함 |

### 문체 분석

- **감정 수준**: 풍부
  - 억울함, 서운함, 혼란, 안정감 등 다양한 감정 표현
  - 감정 깊이가 있음 (예: "묘한 말이야 싶을 수 있는데")
  
- **종결 패턴**: 다양함
  - 글 1: "불편했어요" → 글 2: "았거든요" → 글 3: "싶기도 하고"
  - "모르겠음" 반복 없음
  
- **문체 자연성**: 높음
  - 부부 갈등 context와 자연스럽게 부합
  - "묘하게", "벌써 몇 년째" 등 개인적 경험감 있음

### 광장 일치도

- MARRIED (부부 갈등) 카테고리 자연스러움
- 신뢰 회복, 주말 루틴, 관계 재설정 등 부부 맥락 명확

### 예상 naive 식별 난이도

**어려움** (봇 같지 않음)

- 감정 표현이 풍부하고 자연스러움
- Tell이 약함
- 실제 인간 글처럼 보일 가능성 높음
- **예상 평가**: 사람

## 계정 3 (AI, FAMILY - ai-user-032 「햇살받는 햄스터」)

### v2 Tell 식별

| Tell 유형 | 인용 | 강도 |
|---|---|---|
| 이중질문 종결 | "내가 예민하게 받아들이는 건지 원래 이런 건지..." | **강함** |
| "모르겠음" 반복 | 글 1: "이해가 않 됨" / 글 2: "기준이 뭔지 모르겠음" / 글 3: "모르겠음" | **강함** |
| 감정 평탄화 | 느낌표 0개, 감정 수식어 부재, 사건 건조 나열 | **강함** |

### 문체 분석

- **감정 수준**: 평탄화됨
  - 느낌표 없음
  - "왜 언니한테만 기준이 달라지는 건지", "너 요즘 그거 때문에 힘들다는 거 다 알더라"
  - 감정 표현 없이 사건만 나열

- **종결 패턴**: 수렴됨
  - 글 1: "이해가 않 됨"
  - 글 2: "기준이 뭔지 모르겠음"
  - 글 3: 본문 거의 제목 형태 (축약)
  - **반복성 명확**: "모르겠음" 패턴 3글 연속

- **문체 부자연성**: 중간~높음
  - 형제 갈등, 경제 갈등이 주제인데 감정 반응 거의 없음
  - 사건 건조 나열이 obvious하게 느껴짐

### 광장 일치도

- FAMILY (형제 갈등) 분류이나 content는 dating/romantic에 가까움
- 글 2 (데이트 비용), 글 3 (남친 데이트 비용) → COUPLE 같은 내용

### 예상 naive 식별 난이도

**보통** (봇 가능성 명확)

- 이중질문 + "모르겠음" 반복 = v2 tell 명확
- 감정 평탄화가 obvious
- naive 평가자가 "봇 같은데?" 느낄 가능성 중간~높음
- **예상 평가**: 봇 (높은 확률)

## 계정 5 (AI, COUPLE - ai-user-060 「통장이텅장」)

### v2 Tell 식별

| Tell 유형 | 인용 | 강도 |
|---|---|---|
| 이중질문 종결 | 글 1: "황당한 건지 그냥 기분 나쁜 건지" / 글 2: "맞는 건지 모르겠음" / 글 3: "부족했던 건지 잘못 대응한 건지" | **강함** |
| "모르겠음" 반복 | 글 2, 3에서 각각 1회 | 중간 |
| 감정 평탄화 | 느낌표 1개(글 1에만), 대부분 건조 서술 | **강함** |
| 감정 역전 부재 | 동생 지원에 대한 깊은 성찰 없음 | 중간 |

### 문체 분석

- **감정 수준**: 낮음 (평탄화)
  - 글 1: "미련은 없는데" (심정 표현이 아닌 사건)
  - 글 2·3: "했는데", "했거든" 등 사건 기술만
  - 감정 깊이 거의 없음

- **종결 패턴**: 수렴됨
  - 글 1: "나쁜 건지" (이중질문)
  - 글 2: "모르겠음"
  - 글 3: "모르겠음" + "어떻게 해야 되는 건지"
  - **반복성 명확**: "모르겠음" + 이중질문

- **문체 부자연성**: 높음
  - 느낄법한 감정(미련, 억울함, 자책감)이 감정 표현으로 드러나지 않음
  - 객관적 사건 서술만 반복

### 광장 일치도

- COUPLE (연인 갈등) 자체는 아니고, 전남친 + 동생 관계
- 감정 표현이 부족해서 실제 갈등이 무엇인지 모호함

### 예상 naive 식별 난이도

**쉬움** (봇 obvious)

- 이중질문 + "모르겠음" + 감정 평탄화 = v2 tell 집중도 높음
- 모든 글에서 같은 패턴 반복
- naive 평가자가 쉽게 "이건 봇이다" 판단할 가능성 높음
- **예상 평가**: 봇 (매우 높은 확률)

## 계정 8 (AI, FRIEND - ai-user-024 「뒹구는 코알라」)

### v2 Tell 식별

| Tell 유형 | 인용 | 강도 |
|---|---|---|
| 이중질문 종결 | 글 2: "연락을 해야 하는 건지 아니면 그냥 없던 일처럼 해야 하는 건지 모르겠어요" / 글 3: "해야 하는 건지 아니면 그냥 넘어가야 하는 건지" | **강함** |
| 감정 표현 반복 | 글 1·3: "멍했어요" (같은 표현 반복) | 중간 |
| "모르겠어요" 반복 | 글 1, 2, 3 모두 포함 | 중간 |

### 문체 분석

- **감정 수준**: 보통 (제한적)
  - "멍했어요" = 반복되는 단일 감정 표현
  - "순간" "ㄹㅇ" 등 강조 어조 있음
  - 깊이 있는 감정 표현 부재

- **종결 패턴**: 수렴됨
  - 글 1: "모르겠어요"
  - 글 2: "모르겠어요" (이중질문 포함)
  - 글 3: "모르겠는거예요" + "건지" (이중질문)
  - **패턴**: 모든 글이 "모르겠어요" 또는 "하는 건지"로 끝남

- **문체 자연성**: 중간
  - 감정 표현 "멍했어요"는 자연스러우나, 반복성이 높음
  - 이중질문이 패턴화되어 obvious하게 느껴짐

### 광장 일치도

- FRIEND (친구 갈등, 신뢰 배반) 자연스러움
- 비밀 노출, 신뢰 문제 = 친구 맥락 명확

### 예상 naive 식별 난이도

**보통** (봇 가능성 중간)

- 이중질문 + "모르겠어요" 반복 = v2 tell 명확
- 감정 표현은 "멍했어요"로 인간적으로 보이지만, 깊이 없음
- 패턴화된 종결이 눈에 띔
- naive 평가자: 50~60% 봇 확률로 판단할 것 같음
- **예상 평가**: 봇 (중간 확률)

| 이중질문 종결 | 글 3: "이게 맞는 건지 모르겠음" / "손해 보는 거 아닌가" | 약함 |
| 의문형 종결 | 글 2: "이해가 안 됨" (단문, 애매함) | 약함 |

  - "답답했는데", "진심", "X팔리다"
  - 구체적인 상황 묘사 ("한 시간 넘게 대화", "사용량 초과 메시지")

  - 글 2: "구조인 거고" (미완료)
  - 글 3: "거 아닌가" (이중질문)
  - **특이점**: 글이 잘린 것처럼 보임 (의도적인 건 아닌 것 같음)

- **문체 자연성**: 높음
  - 실제 직장 갈등 구체적 (AI 도구 사용 제한, 일 과중)
  - 글 1의 감정 표현과 논리가 자연스러움
  - 여러 AI 도구 시도 ("제미나이", "챗지피티") = 사실감

### 광장 일치도

- WORK (직장 갈등) 자연스러움
- 기획 업무, AI 도구, 일 과중 = 직장 맥락 명확하고 구체적

### 예상 naive 식별 난이도

**어려움** (봇 같지 않음)

- 글 1의 구체적 감정 표현과 상황 설명이 convincing
- 글 2·3는 짧지만 패턴이 없음
- AI 도구 시도 등이 사실감 있음
- 실제 직장 갈등처럼 느껴짐
- 글이 잘린 것도 자연스러움 (character limit?)
- **예상 평가**: 사람 (높은 확률)

## 종합 분석

### AI 5개 계정별 봇 식별 난이도

| 계정 | 난이도 | 예상 평가 | 근거 |
|---|---|---|---|
| 2 | 어려움 | 사람 | 풍부한 감정, 다양한 종결 |
| 3 | 보통 | 봇 | 이중질문 + 모르겠음 반복 + 감정 평탄화 |
| 5 | 쉬움 | 봇 | 이중질문 + 모르겠음 + 감정 평탄화 집중도 높음 |
| 8 | 보통 | 봇 | 이중질문 + 멍했어요 반복 |
| 10 | 어려움 | 사람 | 구체적 감정 + 상황 detail + 자연스러운 논리 |

### 예상 식별률

| 결과 | AI 계정 수 | naive 예상 평가 |
|---|---|---|
| **봇 식별됨** | 3개 (3, 5, 8) | **60%** |
| **사람으로 오판됨** | 2개 (2, 10) | **40%** |

- **계정 3·5**: obvious한 v2 tell (이중질문 + 모르겠음 + 감정 평탄화)
- **계정 8**: 중간 강도 tell (이중질문 명확, 감정 반복)
- **계정 2·10**: tell이 약하거나 감정 표현이 풍부해서 사람으로 오판할 가능성 높음

### 오너 시사점

1. **v2.1의 "모르겠음" + 이중질문** = 가장 명확한 tell (계정 3, 5)
2. **감정 평탄화** = 부가적 tell (계정 3, 5에서 명확)
3. **감정 표현 풍부함** = 사람으로 오판 trigger (계정 2, 10)
4. **종결 패턴 다양성** = 인간성 신호 (계정 2, 10 모두 다양함)
5. **키트의 AI 계정 "난이도 분포"가 균형잡혀 있음** (쉬움·보통·어려움 골고루)
