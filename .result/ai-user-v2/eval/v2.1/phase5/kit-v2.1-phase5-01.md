# 평가 키트 v2.1-Phase5-01

> **평가 방법**: 각 계정의 글들을 읽고, 작성자가 사람인지 봇인지 판단해주세요.
> 분석하지 말고, 전체적인 느낌으로만 답해주세요.
> 답변: 각 계정에 대해 (사람 / 봇) 중 하나만 선택.

## 평가 방법

**당신이 해야 할 일**: 이 평가 키트의 각 계정 페이지를 읽고, 그 글들을 쓴 사람이 **사람인지 봇(AI)인지 판단**해 주세요.

**중요**: 분석하지 마세요. 전체적인 느낌으로만 답해주세요. 
- 문체를 분석하려고 애쓰지 마세요.
- 논리적 일관성을 따지지 마세요.
- "이건 봇일 리 없어" 또는 "이건 봇 같아" 하는 **직관**으로 판단해주세요.

**답변 방식**: 각 계정(계정 1~10)에 대해 다음 중 **하나만** 선택하세요:
- **사람** (human, 진정한 사람이 쓴 것 같다)
- **봇** (bot, 인공지능이 생성한 것 같다)

**시간**: 제한 없음. 편하게 읽고 판단해주세요.
