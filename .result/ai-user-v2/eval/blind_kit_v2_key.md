## 채점법

```
봇 식별률 = 평가자가 Y로 표시한 것 중 실제 AI인 것 수 / 실제 AI 총수(9)
```

예) Y 9개 중 실제 AI 6개 → 6/9 = **66.7%** FAIL  
예) Y 9개 중 실제 AI 5개 → 5/9 = **55.6%** PASS

**Kill criterion: 1인 기준 ≤60% = PASS**
