## 채점법

평가자 1인당:
```
봇 식별률 = 평가자가 Y로 표시한 것 중 실제 AI인 것 수 / 실제 AI 총수(9)
```

예) Y로 표시한 9개 중 6개가 실제 AI → 식별률 = 6/9 = **66.7%** (FAIL)  
예) Y로 표시한 9개 중 5개가 실제 AI → 식별률 = 5/9 = **55.6%** (PASS)

**집계 기준**: ≥3인 평가자 식별률 **평균** ≤60% = PASS

## Named-Tell 집계 양식

평가자가 "이유" 열에 적은 내용을 아래 표에 옮겨 씁니다.

| 포스트 | 평가자 이유 기록 | AI 확인 | 실제 tells (사후 분석) |
|---|---|---|---|
| P2  | "모르겠음", "이게 맞는 건가 싶음" AI 패턴 | ✓ | 말미 수렴 종결 |
| P4  | 마무리가 사실 열거로만 끝남 | ✓ | 감정·질문 없는 종결 |
| P6  | 비슷한 주제 반복 + 말투 유사 | ✓ | 팀장 갑질 주제 균일성 |
| P8  | 블라인드 테스트 단골주제 | ✓ | MARRIED 주제라 어렵지만 탐지됨 |
| P10 | AI 특유의 장황한 글 | ✓ | 사실열거 종결 + "모르겠음" |
| P12 | 현실성 없는 글이 AI 티 남 | ✓ | 욕설 갑질 반복 구조 |
| P14 | (미탐지 — N으로 오답) | **✗** | MARRIED 페르소나: WORK와 달리 패턴 인식 안 됨 |
| P16 | 비슷한 내용 블라인드 테스트 너무 많이 봤음 | ✓ | 팀장 갑질 주제 반복 |
| P18 | 비슷한 주제 반복 + "정신 못 차리겠음" 부자연 | ✓ | 말미 수렴 종결 |

**사후 분석에서 알려진 주요 tells** (평가 전 기입 금지):
- WORK 페르소나 (043, 061): "지난주 [요일]에 팀장이..." 반복 개구부
