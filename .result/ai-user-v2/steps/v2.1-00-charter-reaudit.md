## Kill Criterion 연표 감사

1. Phase 0 당시: `charter-v2.1.md`와 `steps/v2.1-00-charter.md`는 kill criterion이 오너 확정 대기 상태였음을 기록함.
2. 같은 날 후속 확정: `decisions.md` V2-D05가 "제안값 그대로 확정"을 기록함.
3. 현재 권위본: `STATE.md` Kill Criterion 현황은 `≤60%`, `naive ≥3인`, `통합 평균`을 확정값으로 유지함.
4. 판정: 연표는 일관된다. Phase 0 문서의 pending 표현은 역사 기록으로 보존하고, 현재 상태는 `STATE.md`와 `decisions.md`로 읽어야 한다.
