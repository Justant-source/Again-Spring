- 글1: "4년 경력 + 빠른 속도 = 일 몰림"
- 글2: "팀에서 빠른 속도 = 추가 일 몰림"  
- 글3: "4년차 + 빠른 속도 + 몰리는 일"
- **변주**: ①친구 얘기 ②지인 얘기 ③후배 얘기 (화자만 변경)
- **공통**: "경력 쌓으면서 자연스럽게 그렇게 된 거" (글1·글3 동일 표현)

- 글1: "친구 얘기 → 양쪽 입장 이해" (제3자 보고)
- 글2: "지인 직장 얘기" (제3자 보고, 친구 아님)
- 글3: "후배한테 카톡" (사실상 work 갈등인데 FRIEND로 분류)
- **실제 소재**: 모두 **직장 팀 구조 문제** (WORK 광장 기대값)
- FRIEND 광장으로는 "친구와의 신뢰 문제" "친구 선택의 고민" 등이 맞음

**T2 평가**: **없음** ✓

**T4 평가** (종결 다양성): **단조** ✗

- 글2: "이거 뭐가 맞는 건지 모르겠음" (명확한 의문, 특유 클리셰)
- 글3: "경력 쌓이면서 요령이 생긴 거고 딱히 비법 같은 건 없다는데" (제3자 대사로 탈출)

- 글3: 순전히 팀 구조 문제, 배우자 언급 없음 — **WORK가 맞음**

> AI 식별률·humanness PASS/FAIL은 **Phase 8 naive 사람 ≥3인 블라인드 평가로만** 판정한다(v2.1 불변식: proxy/LLM-judge를 humanness 게이트로 금지).
> 아래 어떤 수치도 식별률 예측이 아니며, LLM 관찰자의 tell 카운트일 뿐이다.

### 현황 (Phase 6 이후) — tell 빈도 관찰
- 위험 계정 2개(ai-user-057·ai-user-035)에서 T1(동일사건반복)·T3(광장불일치)가 강하게 잔존 — tell 빈도 높음
- 양호 계정 3개(ai-user-043·060·032)는 소재 다양성 확보 — tell 빈도 낮음

### 유지해야 할 것
- T1 다양함 (ai-user-043·060·032): 소재 구성 우수
- T2 미완 ✓: 모든 계정이 완성도 높음
- T3 부분 개선: 광장별 프롬프트가 어느 정도 작동

### 개선 후보 (⚠️ Phase 8 측정 완료 후에만 실행 — 측정 전 변경 시 대상 오염)
1. **ai-user-057 비활성화 또는 재훈련**
   - 같은 사건 반복 75% 이상
   - 광장 불일치 (WORK를 FRIEND로 분류)
   - Phase 6 후에도 개선 없음

2. **ai-user-035 사건 다양화**
   - WORK 페르소나와 완전 중복 (ai-user-043과 동일 사건 구조)
   - MARRIED 특화 사건 프롬프트 필요 (배우자 갈등 심화 등)

3. **ai-user-032 종결 다양화**
   - "이게 맞는 건지 모르겠음" 클리셰 감지율 개선
   - 광장 분류 재검증 (COUPLE↔FAMILY 혼동)

### tell 빈도 관찰 요약 (humanness 판정 아님)
- Phase 6 결정론 다양화로 **종결 다양화(T4)·클리셰 반복은 빈도 감소** 관찰
- 그러나 **사건 수준 T1 반복(ai-user-057·035)은 빈도 잔존**
- tell 빈도 낮은 계정 3/5 (043·060·032), 높은 계정 2/5 (057·035)
- ⚠️ 이 분포가 Phase 8 식별률로 이어지는지는 **naive 평가로만 확인 가능** — 여기서 단정 금지

**권장 (Phase 8 결과 확인 후 실행)**:
- 위험 계정 2개 즉시 검토/비활성화
- 나머지 3개 계정은 일반 운영 가능
- Phase 7(또는 재훈련)에서 T1 반복 근본 해결 필요 (프롬프트 가이드 강화)
