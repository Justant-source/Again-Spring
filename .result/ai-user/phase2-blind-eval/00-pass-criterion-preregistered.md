# Phase 2 Pass Criterion — 사전 등록 (측정 전 확정)

> ⚠️ 이 파일은 블라인드 평가 **실시 전**에 작성됨. 결과가 나온 후에 기준을 바꾸지 않는다.
> 생성 시각: 2026-06-21 (Phase 2 실행 중)

---

## 평가 설계

| 항목 | 값 |
|---|---|
| **평가 단위** | **계정 타임라인** (글+댓글 연속 N개) — 단일 글 A/B 쌍 아님 |
| **평가자** | 오너(사용자) + 친구 1~2인 |
| **질문** | "이 계정은 봇인가, 사람인가?" (계정당 1개 판정) |
| **자료 구성** | AI 계정 타임라인 2개 + 실제 THEQOO 유저 타임라인 2개 (총 4개 계정, 순서 랜덤) |

## Pass 기준 (사전 등록 — 변경 불가)

> **봇 정확 식별률 ≤ 60%**

- 계산: (AI 계정 중 "봇"으로 올바르게 맞춘 건수) / (AI 계정 총 수 × 평가자 수)
- 예시: AI 계정 2개 × 평가자 3명 = 6 판정. 이 중 4개 이하 정확 식별 → **PASS**
- 이론적 우연 정확도 = 50%. 60% = 우연 대비 여유 10%.
- 기준 근거: D-101 cond5 임계와 동일 선상 (gap_hi=0.54 보수 상한 도입 전 원래 임계)

## 처리 원칙

- **Pass (≤ 60%)** → Goal A 달성 확정, Phase 3로. 추가 라운드 없음.
- **Fail (> 60%)** → Goal B out-of-scope 재확인, 아카이브, 정지. 추가 라운드 없음.
- **결과와 무관하게 라운드 반복 없음** (plan 금지 안티패턴 §5).

## 기록 의무

평가 완료 후 결과를 `01-blind-eval-results.md`에 기록해야 Phase 2 gate가 완료됨.
