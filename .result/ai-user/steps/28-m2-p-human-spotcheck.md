## 역전 원인 분석 (확정)

N1은 링크지배·공지 스팸을 제거했으나, **corpus 장르 편향**은 해결하지 못함:

| corpus | 구성 | 특성 |
|---|---|---|
| label=human (387행, N1 정제후) | 갈등 서사 POST | 다양 — 일부 격식체, 일부 감정체 혼합 |
| label=ai (158행, T8 이후) | 오케스트레이터 출력 | T8 features 주입 후 **슬랭체 증가** (ㅠㅠ/헐/ㄷㄷ 포함) |

→ 판별기가 학습한 패턴: **"슬랭/구어 ≈ AI (T8 출력 패턴), 격식/구조 ≈ human (일부 human corpus)"**

AUC=0.9994가 여전히 높은 이유: 역전된 방향으로 매우 자신있게 구별함. 방향 자체가 틀림.

## 영향: Best-of-N 리랭커가 출력을 오히려 악화시킴

현재 상태에서 /rerank 사용 시:
- 선택: 격식 상담사 스타일 초안 (P(human)=HIGH → argmax)
- 거부: 슬랭/구어체 초안 (P(human)=LOW)
→ 사람과 **가장 다른** 출력을 "최우수"로 선택

이것이 A-B test Round 3 (Δ=+0.4834)가 노이즈이자 UNVERIFIED인 추가 증거:
리랭커가 역전 판별기로 최악의 출력을 선택하면서도 MAUVE가 +0.4834 나온 것은 **측정 자체의 노이즈 산물**.

## 근본 수정 방향 (M7 연계)

두 가지 경로 중 하나:

### 경로 A: corpus 장르 균형 재조정
- human corpus: 순수 슬랭/감정체 서사만 → 격식체 갈등 서사 제거
- AI corpus: T8 이후 출력(슬랭체)만이 아닌 T8 이전(격식체) 포함
- 단점: human corpus 대폭 감소 우려

### 경로 B: 코드 버그 확인 (확률 인덱스 역전)
- `clf.predict_proba(X)[0][1]` = P(class=1=human) 맞는지 확인
- 만약 `[0][0]` = P(class=0=AI)를 반환하고 있다면 1줄 수정으로 해결
- discriminator.py 또는 routes_score.py 확인 필요

**즉시 확인 권장**: 경로 B (코드 버그) 가능성. 1줄 버그면 즉시 수정 가능.

- N1 디오염(링크스팸 제거)은 corpus 오염 원인의 "절반"만 해결
