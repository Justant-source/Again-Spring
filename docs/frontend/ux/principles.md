# FE UX 원칙 — 다시봄 광장형 (권위본)

> 이 문서는 다시봄 프론트엔드의 UX 의사결정 권위본입니다.  
> 2026-06-02 광장형 피벗 기준. CLAUDE.md 요약본의 상세 버전.

## 철학적 기반

> **"공감이지 판결이 아니다"**

다시봄의 AI 배심원단은 법정 배심원이 아닙니다.  
배심원은 유죄·무죄를 선고하는 것이 아니라 **공감을 표현**합니다.

커뮤니티 투표도 마찬가지입니다 — "누가 잘못했나요?"가 아니라 "어느 입장에 더 공감이 가나요?"

이 구별이 모든 카피·디자인·AI 출력의 기준입니다:
- 배심원 의견 → 공감 비율 (X% : Y%), 관점 표현, 페르소나 목소리
- 배심원 의견 ≠ 과실 판단, 유죄 선고, 가해자 낙인

---

## 1. 핵심 원칙

### 1-1. AI 신뢰성 최우선
- 배심원 의견·중립화 요약은 **항상 AI 생성임을 명확히 표시** (레이블, 아이콘, 색상 구분)
- AI 출력과 사용자 글은 **시각적으로 분리** (배경색, 테두리, 타이포그래피)
- AI 불확실성 인정: "AI가 분석한 결과입니다" 등 면책 문구 포함

### 1-2. 양측 색상 시스템 — 앱 전체 일관 적용
| 대상 | 색상 | 용도 |
|---|---|---|
| 작성자(A측) | 피치(#C9785A) | FeedCard A측, JurorCard A편향, VoteBar A |
| 상대방(B측) | 세이지(#5F8F76) | FeedCard B측, JurorCard B편향, VoteBar B |
| 중립 | 회색 계열 | 커뮤니티 댓글, 중립 배심원 |

**규칙**: 피치/세이지 색상을 A/B 이외의 의미로 사용 금지.

### 1-3. 판결·처방 표현 금지 (AI 출력에만 적용)
**금지 표현** (AI 생성 텍스트에서):
- `판결했다` / `이겼다` / `졌다` / `맞다` / `틀렸다`
- `처방: 헤어지세요` 등 지시형
- `과실비율 X:Y`

**대체 표현**:
- `공감 비율 X:Y` / `공감도`
- `작성자 측 관점` / `상대방 측 관점`
- `A 페르소나는 ~라고 봅니다`

**사용자 입력에는 미적용**: 사용자가 직접 쓴 텍스트의 표현 책임은 사용자에게 있음.

### 1-4. 사용자 입력 필터 미적용 원칙
- 사용자가 게시글·댓글에 입력한 텍스트는 필터링하지 않음
- 위기 키워드가 포함된 경우: 관리자 위기 마크(admin crisis flag) + 상시 핫라인 리소스 노출
- **입력 차단·세션 중단 없음** — 광장형 모델에서 사용자 자율성 존중

## 2. 컴포넌트별 UX 규칙

### 2-1. FeedCard (`components/community/c3/FeedCard`)
- 사연 제목·카테고리·공감 비율 요약 표시
- 배심원 요약이 있으면 "AI 분석" 레이블 + 요약 미리보기
- 게스트: 클릭 시 로그인 유도 (차단 없음, 게시글 목록은 공개)

### 2-2. JurorCard (`components/community/c3/JurorCard`)
- 배심원 페르소나명 + 한 줄 소개 + 편향 표시(A측/B측/중립)
- "AI 배심원" 레이블 필수
- 의견 전체 클릭 시 펼침 (상세 페이지 진입)

### 2-3. VoteBar (`components/community/c3/VoteBar`)
- 투표 비율: 실제 집계값 (%) 표시 — 임의값 금지
- A측=피치(#C9785A), B측=세이지(#5F8F76) 일관 유지
- 투표 전/후 상태 구분 (완료 시 비율 표시, 재투표 금지)

### 2-4. CommentBar / CommentComposeSheet
- 댓글 무한스크롤 (인라인 통합)
- 댓글 작성자 닉네임 표시
- 로그인 필요 시 CommentComposeSheet에서 로그인 유도

### 2-5. 위기 처리 (CrisisResourceModal)
- 닫기: ESC·바깥 클릭으로 닫히지 않음 (의도적 동작)
- 핫라인 링크: 클릭 가능, 외부 리소스로 이동
- 관리자가 게시글에 crisis flag 설정 시 상세 페이지에서 표시

## 3. 페이지별 UX 흐름

### 3-1. 피드 (`/community`)
1. 로그인 여부 무관 피드 열람 가능 (게스트 허용)
2. 무한스크롤 / 카테고리 필터
3. 게시글 카드 클릭 → 상세 페이지

### 3-2. 사연 작성 (`/community/new`)
1. 로그인 필수 (게스트 → 로그인 유도)
2. 관계 카테고리 선택, A·B 입장 작성
3. partner_token 발행 → 초대 링크 (`/s/{token}`)
4. publish 선택: 상대방 미작성 시에도 혼자 게시 가능

### 3-3. 사연 상세 (`/community/[id]`)
1. 비공개 초대: token 기반 접근 (`/community/[id]/invite` 또는 `/s/{token}`)
2. 공개 게시 후: 배심원 의견·공감 비율·커뮤니티 투표·댓글 노출
3. 비로그인 열람 허용, 투표/댓글은 로그인 필요

### 3-4. 알림 (`/notifications`)
- 배심원 분석 완료, 댓글, 좋아요 등 실시간성 알림
- 읽음 처리 후 30일 삭제
