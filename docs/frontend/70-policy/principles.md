# FE UX 원칙 — 다시봄 광장형 (권위본)

> 이 문서는 다시봄 프론트엔드의 UX 의사결정 권위본입니다.  
> 광장 사연 + 커뮤니티 공감 투표 기준. CLAUDE.md 요약본의 상세 버전.

## 철학적 기반

> **"공감이지 판결이 아니다"**

다시봄의 공감 비율은 법정 판결과 다릅니다.  
커뮤니티 투표는 "누가 잘못했나요?"가 아니라 "어느 입장에 더 공감이 가나요?"입니다.

이 구별이 모든 카피·디자인·AI 출력의 기준입니다:
- 공감 비율 → 작성자(A) : 상대방(B) %, 관점 표현
- 공감 비율 ≠ 과실 판단, 유죄 선고, 가해자 낙인

## 1. 핵심 원칙

### 1-1. AI 신뢰성
- AI-user·AI 생성 콘텐츠는 **항상 AI임을 명확히 표시** (레이블, 시각 구분)
- AI 출력과 사용자 글은 **시각적으로 분리** (배경색, 테두리, 타이포그래피)
- AI 불확실성 인정: 면책·안내 문구 포함

### 1-2. 양측 색상 시스템 — 앱 전체 일관 적용
| 대상 | 색상 | 용도 |
|---|---|---|
| 작성자(A측) | 피치(#C9785A) | FeedCard, SideStory, VoteBar A |
| 상대방(B측) | 세이지(#5F8F76) | FeedCard, SideStory, VoteBar B |
| 중립 | 회색 계열 | 일반 커뮤니티 댓글 |

**규칙**: 피치/세이지 색상을 A/B 이외의 의미로 사용 금지.

### 1-3. 판결·처방 표현 금지 (AI 출력에만 적용)
**금지 표현** (AI 생성 텍스트에서):
- `판결했다` / `이겼다` / `졌다` / `맞다` / `틀렸다`
- `처방: 헤어지세요` 등 지시형
- `과실비율 X:Y`

**대체 표현**:
- `공감 비율 X:Y` / `공감도`
- `작성자 측 관점` / `상대방 측 관점`

**사용자 입력에는 미적용**: 사용자가 직접 쓴 텍스트의 표현 책임은 사용자에게 있음.

### 1-4. 사용자 입력 필터 미적용 원칙
사용자 게시글·댓글에는 금지어 필터를 적용하지 않는다. 위기 감지는 서버 `CrisisDetector` + 관리자 관제.

## 2. 핵심 화면 규칙

### 2-1. FeedCard
- 카테고리·닉·시간 / 제목 / 본문 미리보기 / 투표·댓글·조회
- 하단 색 비율 막대(미니 VoteBar)

### 2-2. VoteBar / SideStory
- 작성자 vs 상대방 인라인 투표
- 기표 도장으로 완료 표식

### 2-3. CommunityComment
- 진영 댓글은 `*` + 진영색
- BEST 상단 고정

### 2-4. 게시 (`/community/new`)
- 원문 게시 후 투표·댓글이 제품 핵심 (작성자 vs 상대방 공감)

### 2-5. 알림
- 댓글, 좋아요, 투표 등
