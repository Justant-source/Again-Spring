# 사연 끝맺음 참여 유도 조사

작성일: 2026-06-24  
목적: 향후 `끝맺음`, `댓글 유도`, `투표 참여 유도` 기능 설계 시 재사용할 기준값 정리

## 한 줄 요약

- 사연형 갈등글의 끝맺음만 기준으로 보면, `명시적으로 의견/조언/판단을 구하는 글`은 대략 `15.6%` 수준으로 추정됐다.
- 90% 신뢰구간은 `11.9% ~ 19.2%`다.
- 즉, 대부분의 글은 끝에서 직접 조언을 구하기보다 `감정 토로` 또는 `상황 진술`로 마무리된다.

## 데이터 범위

분석 소스:

- `natepan`
- `BLIND`

원본 접근:

- `ai-learning`의 `/examples/export?contentType=POST&sourceClass=human`

모집단 필터:

1. `POST` 원글만 사용
2. `natepan`, `BLIND`만 사용
3. `plaza_classifier` 기준 `OTHER` 제외
4. 기사/광고/연예뉴스성 패턴 제거
5. `나/저/우리/남편/회사/...` 등 자기 경험 서술 흔적이 있는 `사연형` 글만 사용

위 필터를 거친 모집단 크기:

- `N = 1,311`

## 표본 설계

사용 기준:

- 신뢰수준: `90%`
- 허용 오차: `±5%p`
- 최악 가정 비율: `p = 0.5`

계산 결과:

- Cochran 무한모집단 기준: `270.6`
- 유한모집단 보정 후 필요 표본: `225`

이번 조사에서는 `225개` 표본만 사용했다.

## 조작적 정의

이번 문서의 핵심 지표는 아래 하나다.

`의견 요청형 끝맺음`

끝부분 1~2줄 안에 다음 신호가 있는 경우로 잡았다.

- `의견`, `조언`, `댓글`, `답변 부탁`
- `다들 어떻게 생각`
- `제가 예민한 건가요`
- `이게 맞나요 / 맞는 건가요`
- `도와주세요`
- `어떻게 해야 할까요`
- `추천 좀`
- `어때요 / 어때?`

중요:

- 글 전체 맥락이 아니라 `끝맺음 문구`만 본다.
- 그래서 실제로는 도움을 기대했더라도 끝부분에 직접 쓰지 않으면 `비의견 요청형`으로 분류된다.

## 표본 결과

기준 표본:

- 랜덤 시드 `11`
- 표본 수 `225`

결과:

- 의견 요청형: `35 / 225 = 15.6%`
- 90% 신뢰구간: `11.9% ~ 19.2%`

같은 조건으로 시드만 바꿔 재표집한 안정성 점검:

- seed `21`: `13.3%`
- seed `31`: `16.0%`
- seed `41`: `12.0%`

즉, 실무적으로는 다음 정도로 보는 것이 안전하다.

- `명시적 의견 요청형 끝맺음 비율`: 대략 `12% ~ 16%`
- 보수적 운영 범위: `10%대 중반`

## 해석

이 데이터는 다음을 시사한다.

1. 모든 갈등 사연이 끝에서 사람들의 조언을 직접 구하지는 않는다.
2. 기본적인 인간형 사연 톤은 `하소연`, `상황 정리`, `감정 배출` 쪽이 더 많다.
3. 끝맺음에 매번 `어떻게 생각하세요?`를 붙이면 실제 코퍼스보다 과도하게 유도형이 된다.

## 향후 기능 설계에 바로 쓰는 규칙

### 1. 끝맺음 강화

- 기본값을 `의견 요청형`으로 두지 않는다.
- 기본 끝맺음은 `감정 잔상형` 또는 `상황 미해결형`이 더 자연스럽다.
- 명시적 참여 유도 끝맺음은 전체의 `10%~20%` 범위에서 제한적으로 쓰는 것이 안전하다.

예시 방향:

- 감정 잔상형: `아직도 너무 답답하다`, `이게 계속 마음에 남는다`
- 상황 미해결형: `당장 답은 못 내리겠다`, `계속 이렇게 가도 되나 싶다`
- 제한적 의견 요청형: `제가 예민한 건가요?`, `다들 어떻게 보세요?`

### 2. 댓글 유도

- 댓글 유도는 `직접 질문`보다 `해석 여지`를 남기는 방식이 더 자연스러울 수 있다.
- 즉, 댓글 유도는 반드시 문장 끝에서 노출할 필요가 없다.
- `상황이 애매하게 남는 결말`도 댓글 참여를 유발할 수 있다.

### 3. 투표 유도

- 투표 유도는 `조언 요청형`과 별개로 봐야 한다.
- 투표는 `누가 더 공감되는지`, `어느 쪽이 더 이해되는지`가 드러나는 갈등 구도가 중요하다.
- 따라서 끝맺음을 직접 질문형으로 바꾸기보다, 마지막 문장에서 `갈등 축`을 더 선명하게 남기는 편이 유리할 수 있다.

## 제품 가설

향후 실험 가설:

1. `의견 요청형` 끝맺음은 댓글 수를 늘릴 수 있다.
2. 하지만 과도하게 쓰면 인간형 자연스러움이 떨어질 수 있다.
3. `감정 잔상형 + 미해결형` 끝맺음이 오히려 자연 댓글을 더 유발할 가능성이 있다.
4. 투표 전환은 `질문형 끝맺음`보다 `양측 대비가 또렷한 마지막 문장`의 영향을 더 받을 수 있다.

## 구현 전 체크리스트

- 끝맺음 템플릿을 `감정형 / 미해결형 / 의견요청형`으로 분리할 것
- 기본 분포는 `의견요청형 과다`가 되지 않게 제한할 것
- 플랫폼별 차이를 따로 보려면 `Blind` 표본을 별도 층화추출할 것
- 성과 측정은 `댓글 수`, `첫 댓글 도달 시간`, `투표 수`, `체류 시간`으로 나눌 것
