# 다시봄 개인정보처리방침

**최종 개정일**: 2026-05-08
**시행일**: 2026-05-08
**버전**: 베타 v1.0

---

다시봄(이하 "서비스")은 회원의 개인정보를 중요시하며, 한국 개인정보보호법(PIPA)을 준수하기 위해 노력합니다. 본 개인정보처리방침은 회원이 제공한 개인정보가 어떠한 목적으로 사용되며, 어떻게 보호되는지를 안내합니다.

---

## 1. 개인정보 처리 목적

다시봄은 다음의 목적을 위해 개인정보를 처리합니다:

1. **회원 가입 및 본인 확인**
   - 회원 가입 의사 확인, 회원 식별, 본인 인증
   - 비밀번호 재설정 및 계정 관리

2. **서비스 제공**
   - AI 기반 대화 및 1차 조언 제공
   - 세션 관리 및 리포트 생성
   - 의견 수신 및 답변

3. **서비스 품질 향상**
   - 운영자가 대화 내용을 검토하여 AI 응답 품질 개선
   - 버그 디버깅 및 오류 원인 파악
   - UX 개선

4. **부정 이용 방지**
   - 게스트 어뷰즈 차단 (IP 단위 사용량 제한)
   - 다중 계정 생성 차단

5. **위기 상황 대응**
   - 회원이 위기 상황을 신고한 경우 안전 우선 대응

## 2. 수집하는 개인정보 항목

### 2.1 필수 수집 항목

회원가입 및 서비스 이용을 위해 다음 정보를 필수로 수집합니다:

| 항목 | 수집 시점 | 수집 방법 |
|---|---|---|
| 이메일 주소 | 회원가입 | 회원 직접 입력 |
| 닉네임 | 회원가입 | 회원 직접 입력 |
| 비밀번호 (해시화) | 회원가입 | 회원 직접 입력, BCrypt로 해시 저장 |
| 대화 내용 | 서비스 이용 | 회원이 채팅창에 입력 |

### 2.2 선택 수집 항목

다음은 회원의 선택에 따라 수집됩니다:

| 항목 | 수집 시점 | 비고 |
|---|---|---|
| MBTI | 회원가입 또는 프로필 설정 | AI 응답 개인화 |
| 대화 스타일 선호도 | 회원가입 또는 프로필 설정 | AI 응답 개인화 |
| 마케팅 수신 동의 | 회원가입 | 수신 거부 가능 |

### 2.3 자동 수집 항목

서비스 이용 과정에서 다음이 자동으로 수집됩니다:

| 항목 | 수집 목적 |
|---|---|
| IP 주소 | 어뷰즈 방지, 세션 관리 |
| User-Agent (브라우저·디바이스 정보) | 디버깅, 호환성 확인 |
| 접속 일시 | 서비스 분석, 보안 |
| 쿠키, 세션 토큰 (JWT) | 로그인 유지 |

### 2.4 수집하지 않는 정보

다시봄은 다음 정보를 수집하지 않습니다:
- 정확한 위치 정보 (GPS)
- 디바이스 식별자
- 결혼 여부, 자녀 수, 직업 등 (대화 중 자연스럽게 등장하면 대화 내용에 포함)
- 신용카드, 주민등록번호 등 금융·식별 정보 (베타 단계 무료 운영)

## 4. 개인정보 처리 위탁

다시봄은 AI 응답 생성을 위해 다음 외부 서비스에 데이터를 위탁합니다:

| 항목 | 내용 |
|---|---|
| 위탁 대상 | Anthropic, PBC (미국) |
| 위탁 업무 | AI 응답 생성을 위한 데이터 처리 (Claude 모델 호출) |
| 위탁 항목 | 회원 메시지, 세션 컨텍스트 (회원 식별 정보는 포함하지 않음) |
| 보유·이용 기간 | Anthropic 정책에 따름 (일반적으로 30일) |
| 국외 이전 여부 | 미국 (Anthropic 본사로 데이터 전송) |

본 위탁은 한국 개인정보보호법에 따른 국외 이전에 해당하며, 회원가입 시 동의를 받습니다. 동의를 거부하면 본 서비스를 이용할 수 없습니다 (AI 응답 생성이 핵심 기능이므로).

위탁 외에 운영자는 회원의 개인정보를 외부에 제3자에게 제공하지 않습니다.

## 6. 개인정보 파기 절차

### 6.1 자동 파기

운영자는 다음 cron 작업을 통해 보유 기간이 경과한 데이터를 자동 파기합니다:

- 매일 새벽 4시 (KST): 데이터 보유 기간 검사 및 파기

### 6.2 파기 방법

- **전자적 파일**: 복원 불가능한 방법으로 영구 삭제 (DELETE 후 vacuum 또는 secure_delete)
- **출력물**: 본 서비스는 종이 출력물을 보유하지 않음

### 6.3 위탁 데이터 파기

Anthropic으로 전송된 데이터는 Anthropic의 정책에 따라 처리됩니다. 운영자는 회원이 요청하면 Anthropic에 해당 회원 데이터의 삭제를 요청합니다.

## 7. 개인정보 보호 조치

운영자는 회원의 개인정보를 안전하게 관리하기 위해 다음 조치를 취합니다:

### 7.1 기술적 조치
- 비밀번호 BCrypt 해시 저장
- 통신 구간 HTTPS 암호화 (TLS 1.2 이상)
- 데이터베이스 외부 직접 접근 차단 (방화벽)
- 접근 권한 관리 (운영자 본인만 admin 권한)

### 7.2 관리적 조치
- 개인정보 처리 목적별 접근 권한 분리
- 운영자의 데이터 열람 시 사유 기록
- 정기적 보안 점검

### 7.3 외부 위탁 보호
- Anthropic과의 위탁 계약을 통한 보호 의무 부과
- 위탁 시 회원 식별 정보 최소화

### 7.4 개인정보 유출 시 대응
- 유출 발생 즉시 회원에게 통지
- 한국인터넷진흥원(KISA, 118)에 신고
- 유출 원인 파악 및 재발 방지 조치
