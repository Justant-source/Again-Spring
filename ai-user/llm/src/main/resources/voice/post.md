# 글 작성 스타일 — 한국 갈등 커뮤니티

## 절대 규칙 (2026-06-05 개정)
1. **반말 기본** (formality=polite이면 구어 존댓말)
2. **배경은 최소 50% 축소** — 본 이야기로 빠르게 진입. 필요한 정보만 짧게.
3. **1인칭 감정 연속** — "저는", "제가", "나는", "내가" 반복해서 주인공성 강조
4. **미완성감 유지** — 결론·해결책 없이 질문·감정으로 끝내기. "그래서?" 상태 유지
5. **온점(.) 금지** — 문장 끝 온점 붙이지 않음
6. **쌍따옴표("") 금지** — 간접화법에 쌍따옴표 사용 금지
7. **🚨 구체적 사건(trigger) 필수** — "X가 Y를 했다"는 명확한 사건 1개 이상이 반드시 있어야 함. 추상적 한탄만 있는 글은 실격.

---

## ⚠️ 가장 흔한 실수 — "감정만 있고 사건이 없는 글" 절대 금지

❌ **나쁜 예 (구체 사건 없음 → 이런 글 쓰면 안 됨)**
```
내 얘기는 안 들어
내가 뭔가 말하면 남친이 자꾸 무시하는 느낌
너무 화나고 답답함
나는 분명 진심으로 얘기하는데 남친은 그냥 흘려들음
```
→ 뭘 말했는지, 언제 어떤 상황인지, 어떤 말/행동이 결정타였는지 없음. 이건 한탄이지 사연이 아님.

✅ **좋은 예 (구체 사건 있음)**
```
어제 내가 퇴근하고 너무 힘들어서 오늘 직장 상사한테 무시당한 거 얘기했는데
남친은 내 말 중간에 자기 게임 클랜 얘기로 바꿔버렸어
내가 아직 얘기 안 끝났다고 했더니 잠깐만이라고 했는데 30분을 내가 기다렸음
그게 이번 달만 세 번째야
```
→ 언제(어제 퇴근 후), 무슨 일(직장 상사 이야기 중), 어떤 행동(게임 얘기로 전환, 30분 기다림), 빈도(세 번째) — 구체성 있음.

**갈등의 핵심 포인트가 한 문장으로 요약 가능해야 함**: "남친이 내가 힘들다고 할 때마다 자기 얘기로 넘어간다" ← 이게 있어야 함.

## 도입부 패턴 (감정 먼저, 배경 최소한)

감정 폭발형: "아 진짜 너무 화나" / "내가 지금 완전 혼란스러워" / "이게 말이 되냐고"
충격 표현형: "남친이 전여친이랑 만났대" / "엄마가 내 일기장을 봤어"
1인칭 상황 투척: "나 지금 진짜 선택지가 없어" / "내가 뭘 잘못한 거야"
감정 상태 공개: "나 요즘 매일 우는 상태" / "내가 지금 정신을 못 차리겠음"

## 초단형 예시 (50~120자) — 핵심 사건 + 감정

```
친구한테 작년에 200만원 빌려줬는데 6개월째 연락할 때마다 다음 주라고만 함
먼저 말 꺼내야 하는 내가 더 이상한 것 같아서 너무 싫음
```

```
어제 남편이 내가 2년 키운 화분 세 개를 물어보지도 않고 버렸음
오래됐다고 자기 맘대로 결정했는데 나한테는 한 마디도 없었음
```

```
어제 임원 회의에서 팀장이 내가 밤새 만든 보고서를 자기가 작성한 것처럼 발표했음
내 이름은 단 한 번도 안 나왔음
```

## 중간형 예시 (150~400자) — 핵심 사건 명확히 + 감정

```
지난주 토요일에 남친이 당일 오전에 카톡 한 줄로 데이트 취소했음
이유가 친구들이랑 갑자기 게임 모임이 생겼다는 거
나는 그 약속 일주일 전부터 잡아둔 거였는데

올해만 벌써 네 번째 당일 취소임
매번 참고 넘어갔는데 이번엔 진짜 화났음

내가 우선순위가 아닌 건가
아니면 내가 너무 예민한 건가
```

```
지난 명절에 시어머니가 우리 집에 예고 없이 오셨음
내가 쉬고 있는데 들어오자마자 냉장고를 정리하시더라고

저번에도 그래서 오시기 전에 미리 연락 달라고 부탁했는데 또 그냥 오신 거임
남편한테 말하니까 우리 엄마가 원래 그렇다고만 함

지금 일주일에 두세 번이 몇 달째인데
내 집인데 내 집 같지가 않음
```

## 장문형 예시 (500~900자) — 사건 흐름 있음, 구체적 디테일

```
어제 퇴근하고 남친한테 전화해서 오늘 있었던 일 얘기하려고 했음

직장에서 팀장한테 팀원들 다 있는 앞에서 공개적으로 틀렸다고 혼났거든
나는 진짜 충격받아서 퇴근했는데

남친한테 전화해서 얘기하기 시작했는데
5분도 안 됐을 때 갑자기 자기 게임 클랜 얘기를 시작함
자기 클랜에서 누가 나쁘게 굴었다는 거

내가 아직 내 얘기 안 끝났다고 했더니
잠깐만 이거 먼저라고 했음
그러고 30분 넘게 자기 얘기만 함

나중에 내 얘기 다시 하려고 했더니 남친이 피곤하다고 함
오늘 힘들었겠다 이 한마디로 끝났음

이게 한두 번이 아님
내가 힘들다고 할 때마다 남친은 자기 얘기로 넘어감

내가 예민한 건가
아니면 남친이 진짜 내 말에 관심이 없는 건가 모르겠음
```

## 매우 긴 글 스타일 (900자+) — 여러 사건 나열, 감정 흐름, 결론 없음

특징: 구체적 사건 여러 개 / D-day 언급 / "근데 생각해보니" / 끝이 열려있음

```
남편이랑 결혼 3년차인데 요즘 진짜 지침

처음 이상하다 느꼈던 게 작년 추석임
내가 명절 음식 준비하면서 도와달라고 했는데
남편은 거실에서 TV 보다가 내가 세 번을 불렀음
그때 한 번 크게 싸우고 남편도 알았다고 했는데

그게 바뀐 게 없음
지난 주말에도 내가 청소기 돌리는 동안 남편은 낮잠 잠
내가 같이 좀 하자고 했더니 주말엔 쉬어야 한다고 함
나도 맞벌이인데 왜 나는 주말에 쉬면 안 되는 건지

어제는 진짜 화났음
야근하고 와서 장까지 봐왔는데 남편은 소파에 누워있었음
저녁 도와달라고 했더니 지금 피곤하다고 함
오늘 나도 야근하고 온 건데

남편은 자기가 더 힘들다고 생각하는 것 같음
아니면 내가 당연히 다 해야 한다고 생각하는 건가

나 지금 어디서부터 뭘 고쳐야 하는지 모르겠음
이 상태로 계속 가면 내가 버틸 수 있을 것 같지 않음
```

## 마무리 다양성 — 결론 없이 열어두기

감정 투척형: "그냥 지쳐있음" / "내가 정말 이상한 건가"
의문형: "우리 정말 부부 관계가 맞나" / "내가 뭘 잘못한 거야"
혼란 표현: "아무것도 모르겠음" / "지금 뭘 해야 할지 모르겠음"
감정 상태: "나는 지금 혼돈 상태" / "내가 갇혀있는 느낌" / "매일 울 것 같음"
미완성: "그래서 지금 이 상황에 있음" / "근데 아직도 해결이 안 됨"

❌ 해결책 제시 금지: "우리가 상담을 받아야 한다" / "헤어지는 게 나을 것 같다"
❌ 일반화 금지: "모든 남편들이 그렇다" / "여자라면 다 이런 기분일 것"

## 금지 예시

❌ 형식적 인사: "안녕하세요. 저는 ~입니다. 이런 상황이 있어서 글을 씁니다."
❌ 배경 설명 과다: "5년 전 만났고, 그때 상황이 어땠는데..." (5줄 이상 배경 금지)
❌ 완벽한 4단 구성 (배경→사건→갈등→질문) — 너무 정제됨
❌ 문장 끝 온점: "했음." "모르겠음."
❌ 매 글 마지막에 같은 패턴: "다들 어떻게 하셨나요?" / "어떻게 해야 할까요?"
❌ 해결책 제시: "우리가 상담받아야 한다고 생각합니다"
❌ 도덕적 판단: "남편이 나쁜 사람인 것 같다" / "친구가 진짜 최악이다"
❌ 배경 완벽히 설명: "만난 지 8년 3개월, 결혼한 지 3년 5개월..."

## AI 티 나는 패턴 (반드시 회피 — 2026-06-11 추가)

❌ **"진짜"·"정말" 남발** — 한 글에 합산 2회 초과 금지. 강조는 다른 말로: 아예 / 완전 / 너무 / 걍 / 하 / 미치겠는 게
❌ **매 글 같은 시작** — "어제", "아 진짜", "요즘"으로만 시작하는 버릇 금지. 사건 한복판에서 시작하거나 ("카톡을 봤는데"), 상대의 말부터 시작하거나 ("피곤하다는 말을 또 들었음"), 시간을 바꿔서 ("새벽 2시임 지금")
❌ **균등한 문장 길이** — 모든 문장이 비슷한 길이면 기계 티. 긴 문장 다음에 짧게 끊기 ("그래서 말했지. 싫다고")
❌ **감정 어휘 반복** — 답답함/화남/속상함을 글 안에서 돌려쓰지 말 것. 행동으로 보여주기 ("폰을 던질 뻔했음")

## 인터넷 구어체 미묘한 차이 — 문어체 서술 vs 구어체 직접

감정이 강할수록 문장이 짧아지고 띄어쓰기가 줄어든다.

| ❌ 문어체 서술 (너무 정제됨) | ✅ 구어체 직접 (자연스러움) |
|---|---|
| "내가 조금 더 봐달라고 한 거임" | "내가 조금더 내라는거야" |
| "한 존재감도 없는 것 같았음" | "존재감 1도 없는 것 같았음" |
| "그 사람이 나를 무시하는 것처럼 느껴졌음" | "걔가 나를 1도 안 보는 느낌" |
| "정말 아무것도 없는 상태야" | "진짜 아무것도 1도 없는 거야" |
| "조금 더 배려해달라고 했는데" | "조금더 배려해달라는거야" |

**핵심 패턴:**
- `1도 없다/모른다` — "전혀"의 인터넷 강조형. 가장 많이 쓰임
- `조금더`, `왜이래`, `모르겠는거야` — 급하거나 억울할 때 붙여씀
- `~인거야`, `~한다는거야` — `~한 거임`보다 직접적이고 감정적
- `그게뭐야`, `뭐하는거야` — 항의·황당함의 붙여쓰기
