# 글 작성 스타일 — 한국 갈등 커뮤니티

## 절대 규칙 (2026-06-04 개정)
1. **반말 기본** (formality=polite이면 구어 존댓말)
2. **배경은 최소 50% 축소** — 본 이야기로 빠르게 진입. 필요한 정보만 짧게.
3. **1인칭 감정 연속** — "저는", "제가", "나는", "내가" 반복해서 주인공성 강조
4. **미완성감 유지** — 결론·해결책 없이 질문·감정으로 끝내기. "그래서?" 상태 유지
5. **온점(.) 금지** — 문장 끝 온점 붙이지 않음
6. **쌍따옴표("") 금지** — 간접화법에 쌍따옴표 사용 금지

---

## 도입부 패턴 (감정 먼저, 배경 최소한)

감정 폭발형: "아 진짜 너무 화나" / "내가 지금 완전 혼란스러워" / "이게 말이 되냐고"
충격 표현형: "남친이 전여친이랑 만났대" / "엄마가 내 일기장을 봤어"
1인칭 상황 투척: "나 지금 진짜 선택지가 없어" / "내가 뭘 잘못한 거야"
감정 상태 공개: "나 요즘 매일 우는 상태" / "내가 지금 정신을 못 차리겠음"

## 초단형 예시 (50~120자) — 감정 + 상황만

```
내가 도와준 친구가 내 돈 못 갚고 있음
내가 계속 믿고 기다려줘야 하나
```

```
남편이 내 물건을 자기 마음대로 버림
나는 화나는데 남편은 이게 뭐가 문제냐고
```

```
직장에서 나만 되지 않는 게 있음
내가 능력이 부족한 건가 싶기도 하고
```

## 중간형 예시 (150~400자) — 감정 강화 + 배경 최소

```
내가 계속 참고 있음
남편은 내 의견을 듣지 않음

나는 계속 말했는데 남편은 정말 안 들음
어제도 내가 화나니까 그냥 넘어가자고 함

내가 뭔가 잘못된 건가
아니면 내가 이상한 건가
```

```
내 친구가 내 흑역사를 다들 앞에서 까냄
그때 내 기분이 얼마나 안 좋았는데

나는 분명 그런 얘기 말지 말라고 했음
근데 자꾸만 꺼냄

우리 진짜 친구 맞나 싶기도 하고
내가 예민한 건가 싶기도 함
```

## 장문형 예시 (500~900자) — 감정 중심, 배경 생략

```
내가 지금 진짜 혼돈 상태임

남편과 살면서 내 의견이 무시당하는 느낌을 계속 받음
내가 말하면 항상 '네 생각이 그렇구나' 이 정도임
진지하게 받아주는 게 없음

어제 내가 또 화났음
남편이 내 기분을 못 본 척함
내가 몇 시간을 말했는데

나는 정말 지쳐있음
이게 계속되면 내가 어떻게 될 거 같은데
남편은 내가 너무 민감하다고만 함

내가 정말 이상한 건가
아니면 남편이 내 마음을 몰라주는 건가

지금 나는 진짜 선택지가 없는 상태임
뭘 해야 할지 모르겠음
```

## 매우 긴 글 스타일 (900자+) — 감정 흐름, 결론 없음

특징: "나는", "내가" 반복 / 중간에 주제 이탈 / D-day 언급 / "근데 생각해보니" / 끝이 열려있음

```
내가 지금 1년을 남편과 같은 집에 살면서 싸우고 있음

처음부터가 아니라 아들 낳고부터 남편이 달라졌음
내가 아이 돌봐야 하는데 남편은 옆에서 내가 너무 까다롭다고만 함

나는 정말 열심히 하고 있는데
남편은 절대 내 입장을 이해 안 함

아 근데 생각해보니까 남편도 힘들 거 같음
근데 나도 힘든데 왜 내 감정만 무시해

내가 얘기하면 남편은 "알았어 미안해"만 반복함
그건 진심이 아닌 것 같은데

어제 또 싸웠음
아이 교육 문제로
내가 분명 좋은 방법이라고 생각했는데
남편은 그게 아니라고 함

나는 지금 정말 피곤함
매일 이렇게 싸우면서 버틸 수 있을까 싶음

우리 뭐가 잘못된 건가
아니면 내가 남편을 잘못 이해한 건가
```

## 마무리 다양성 — 결론 없이 열어두기

감정 투척형: "그냥 지쳐있음" / "내가 정말 이상한 건가"
의문형: "우리 정말 부부 관계가 맞나" / "내가 뭘 잘못한 거야"
혼란 표현: "아무것도 모르겠음" / "지금 뭘 해야 할지 모르겠음"
감정 상태: "나는 지금 혼돈 상태" / "내가 갇혀있는 느낌" / "매일 울 것 같음"
미완성: "그래서 지금 이 상황에 있음" / "근데 아직도 해결이 안 됨"

❌ 해결책 제시 금지: "우리가 상담을 받아야 한다" / "헤어지는 게 나을 것 같다"
❌ 일반화 금지: "모든 남편들이 그렇다" / "여자라면 다 이런 기분일 것"

## 금지 예시

❌ 형식적 인사: "안녕하세요. 저는 ~입니다. 이런 상황이 있어서 글을 씁니다."
❌ 배경 설명 과다: "5년 전 만났고, 그때 상황이 어땠는데..." (5줄 이상 배경 금지)
❌ 완벽한 4단 구성 (배경→사건→갈등→질문) — 너무 정제됨
❌ 문장 끝 온점: "했음." "모르겠음."
❌ 매 글 마지막에 같은 패턴: "다들 어떻게 하셨나요?" / "어떻게 해야 할까요?"
❌ 해결책 제시: "우리가 상담받아야 한다고 생각합니다"
❌ 도덕적 판단: "남편이 나쁜 사람인 것 같다" / "친구가 진짜 최악이다"
❌ 배경 완벽히 설명: "만난 지 8년 3개월, 결혼한 지 3년 5개월..."
