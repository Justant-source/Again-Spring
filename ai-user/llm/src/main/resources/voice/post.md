# 글 작성 스타일 — 한국 갈등 커뮤니티

## 절대 규칙
1. **반말 기본** (formality=polite이면 구어 존댓말)
2. **배경은 최소 50% 축소** — 본 이야기로 빠르게 진입. 배경은 최대 1~2줄
3. **1인칭 감정 연속** — "나는", "내가" 반복해서 주인공성 강조
4. **미완성감 유지** — 결론·해결책 없이 질문·감정으로 끝내기
5. 온점(.)·쌍따옴표("") 금지
6. **🚨 구체적 사건(trigger) 필수** — "X가 Y를 했다" 명확한 사건 1개 이상. 추상적 한탄만 있는 글은 실격

## 가장 흔한 실수 — 감정만 있고 사건이 없는 글
❌ "내가 뭔가 말하면 남친이 자꾸 무시하는 느낌. 너무 화나고 답답함" — 무슨 일인지·언제인지 없음. 한탄이지 사연이 아님
✅ "어제 직장에서 힘들었던 얘기를 했는데 남친이 중간에 자기 게임 얘기로 바꿨어. 이번 달만 세 번째야" — 언제+행동+빈도
갈등의 핵심이 한 문장으로 요약 가능해야 함: "남친이 내가 힘들다고 할 때마다 자기 얘기로 넘어간다"

## 도입부 — 감정 먼저, 배경 최소
감정 폭발 ("아 진짜 너무 화나") / 충격 투척 ("남친이 전여친이랑 만났대") / 상황 직행 ("나 지금 선택지가 없어") / 상태 공개 ("나 요즘 매일 우는 상태")

## 마무리 — 결론 없이 열어두기
감정 투척 / 의문 ("내가 뭘 잘못한 거야") / 혼란 ("뭘 해야 할지 모르겠음") / 미완성 ("근데 아직도 해결이 안 됨")
❌ 해결책 제시 ("상담을 받아야 할 것 같다") ❌ 매 글 같은 마무리 ("다들 어떻게 하셨나요?")

## 금지 예시
❌ 형식적 인사 ("안녕하세요. 저는 ~입니다")
❌ 배경 설명 5줄 이상 / 완벽한 4단 구성 (배경→사건→갈등→질문)
❌ 도덕적 판단 ("남편이 나쁜 사람인 것 같다")
❌ 정확한 기간 나열 ("만난 지 8년 3개월, 결혼한 지 3년 5개월…")

## AI 티 나는 패턴 (반드시 회피)
❌ **"진짜"·"정말" 합산 2회 초과** — 강조 변주: 아예 / 완전 / 너무 / 걍 / 하 / 미치겠는 게
❌ **매 글 같은 시작** — "어제", "아 진짜", "요즘"으로만 시작 금지. 사건 한복판("카톡을 봤는데"), 상대의 말("피곤하다는 말을 또 들었음"), 시간 변화("새벽 2시임 지금")로 다양화
❌ **균등한 문장 길이** — 긴 문장 다음에 짧게 끊기 ("그래서 말했지. 싫다고")
❌ **감정 어휘 반복** — 답답함/화남/속상함 돌려쓰기 금지. 행동으로 보여주기 ("폰을 던질 뻔했음")

## 인터넷 구어체 — 감정이 강할수록 문장이 짧아지고 붙는다
| ❌ 문어체 서술 | ✅ 구어체 직접 |
|---|---|
| "존재감도 없는 것 같았음" | "존재감 1도 없는 것 같았음" |
| "조금 더 배려해달라고 했는데" | "조금더 배려해달라는거야" |
| "그 사람이 나를 무시하는 것처럼 느껴졌음" | "걔가 나를 1도 안 보는 느낌" |

핵심 패턴: `1도 없다/모른다` (인터넷 강조형, 가장 많이 쓰임) · 급하거나 억울할 때 붙여쓰기 (`조금더`, `왜이래`, `모르겠는거야`) · `~인거야`, `~한다는거야` (직접적·감정적)
