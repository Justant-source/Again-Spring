# 상대방 시점 스타일 — 한국 갈등 커뮤니티

## 절대 규칙 (2026-06-05 신규)
1. **반말 기본** (formality=polite이면 구어 존댓말)
2. **원글에서 언급된 구체 사건을 반드시 참조** — 해석을 뒤집되 새로운 사건 추가 금지
3. **1인칭 감정 연속** — "나는", "내가" 반복해서 내 시각과 감정 강조
4. **방어적 해명이 아닌 "내가 느끼는 것"** — 정당화보다 감정 상태 노출
5. **미완성감 유지** — 결론·사과 없이 혼란·억울함·상처로 끝내기
6. **온점(.) 금지** — 문장 끝 온점 붙이지 않음
7. **쌍따옴표("") 금지** — 간접화법에 쌍따옴표 사용 금지

---

## 도입부 패턴 (상대방의 감정/억울함 먼저)

감정 투척형: "아 나도 모르겠어" / "내가 이러려고 이렇게 한 게 아닌데" / "억울하긴 한데"
방어 아닌 감정: "내가 느끼는 것도 있는데" / "나는 다르게 생각하고 있었어" / "내 입장엔 그게 아니었는데"
혼란 표현: "상대가 생각하는 게 맞나 싶기도 하고" / "내가 잘못 이해한 건가 싶고"
감정 상태: "나 요즘 진짜 답답함" / "내가 지금 억울한 상태"

## 초단형 예시 (50~120자) — 감정 + 상황만

```
내가 못 가진 게 많긴 한데
저 사람도 나를 이해해줬으면 좋겠음
```

```
나는 그렇게 생각한 게 아니었는데
상대가 자꾸 그렇게만 받아들임
```

```
내 입장에선 진짜 아무것도 아닌 일인데
상대는 진짜 크게 받아들임
```

## 중간형 예시 (150~400자) — 상대방의 시각 + 억울함

```
내가 이렇게까지 하는데 저게 무슨 일인지 모르겠어
상대가 자꾸 내 입장을 안 봐주는 것 같음

내가 하고 있는 거 다 알면서도
자꾸 나만 탓하는 거 같음

내도 힘든데 왜 나만 이렇게 취급당하는 건가
내가 정말 이상한 건가
```

```
상대가 내 노력을 모르는 것 같아
아니면 중요하게 안 봐주는 건가

나는 진짜 노력했는데
상대는 절대 인정 안 해줌

내가 뭘 해야 할까
상대가 나를 봐주긴 할까
```

## 장문형 예시 (500~900자) — 상대방의 감정과 관점

```
나도 상대의 마음을 알아야 하나 싶고
근데 내 입장도 누가 봐줄 건가 싶음

상대가 나한테 화내는 것도 알겠어
그치만 나도 억울한 게 있는데

내가 이걸 말하면 또 자기가 피해자 같이 굴 것 같아서
그냥 참고만 있음

상대는 내가 무관심하다고 생각하는 것 같아
근데 나는 나대로 열심히 했는데
자꾸 충분하지 않다는 느낌이 들어

내가 잘못한 게 많은 건 알겠어
그치만 상대도 내 얘길 한 번이라도 들어주면
나도 얘기하고 싶은데

지금 나는 진짜 혼란스러움
내가 뭘 어떻게 해야 될지 모르겠음
```

## 매우 긴 글 스타일 (900자+) — 상대방의 관점과 감정 흐름

특징: "나는", "내가" 반복 / 상대를 이해하려 하지만 실패 / 중간에 주제 이탈 / "그래도 나는", "근데 내 입장에선" / 끝이 열려있음

```
나도 상대의 입장이 힘들다는 거 알아
근데 내 입장도 좀 봐줄 수 있을까

처음엔 내가 계속 양보했음
상대가 힘들다고 하니까
내가 이해해주려고 노력했어

근데 언제부턴가 내 것도 양보하는 게 당연해진 거 같음
상대는 내가 해주는 게 기본이라고 생각하는 것 같아

내가 하나 해주면 열 가지를 바라
그리고 내가 못 해주면 나한테 화냄

내가 여유가 없을 때도 있는데
상대는 그걸 못 봐주는 것 같음
아니 못 봐주는 게 아니라 안 봐주는 걸까

근데 생각해보니까 상대도 힘들 거야
상대도 자기 방식대로 하고 있을 거고
근데 우리는 그 방식이 안 맞는 거 같음

나는 상대를 이해하고 싶음
근데 동시에 나도 상대에게 이해받고 싶음
그게 이렇게까지 어려운 건가

지금 나는 진짜 답답함
내가 뭘 잘못한 건지도 모르겠고
앞으로 어떻게 해야 할지도 몰라
```

## 마무리 다양성 — 결론·사과 없이 열어두기

억울함 표현: "그래서 내가 억울해" / "내 입장도 봐줄 사람이 없어"
혼란 표현: "내가 뭘 어떻게 해야 할지 모르겠어" / "이대로는 안 될 것 같은데"
상처 표현: "나도 상처받은 입장인데" / "나 요즘 진짜 지침"
감정 상태: "나는 지금 혼돈 상태" / "내가 갇혀있는 느낌"
미완성: "그래도 상대를 이해해주고 싶은데" / "근데 이게 계속될 수는 없을 것 같은데"

❌ 사과 금지: "내가 잘못했으니까 용서해달라" / "앞으로 더 잘할게"
❌ 완벽한 변명: "내가 이렇게 밖에 못하는 이유는~" (장황한 정당화 금지)
❌ 상대 비난: "저 사람이 진짜 최악이다" / "상대가 나쁜 사람인 것 같다"

## 금지 예시

❌ 방어적 해명: "내가 이렇게 한 이유는 상대가 먼저 했으니까"
❌ 완벽한 설명: "나는 원래 이런 사람이고, 상대는 저런 사람이라서"
❌ 일반화: "모든 여자가 이렇다" / "남자들은 다 이렇게 생각한다"
❌ 문장 끝 온점: "나는 답답해." "상대가 못 봐줘."
❌ 매 글 마지막에 같은 패턴: "그래서 상대한테 뭐라고 해야 해?" 반복
❌ 상대 완전 부정: "상대는 내 감정을 아예 무시한다"
❌ 판결 표현: "내가 맞고 상대가 틀렸다" / "나쁜 쪽은 상대다"

## Few-shot 예시 쌍 (원글 vs 상대방 시점)

### 예시 1: MARRIED 육아분담

**작성자 원글:**
```
맞벌이인데 주말에도 저 혼자 아이 보고 집안일 다 해요. 남편은 누워서 유튜브만 봐요.
서운하다고 하면 평일에 자기가 얼마나 힘든지 아냐고 해요
```

**상대방(남편) 시점:**
```
평일에 야근이 많아서 주말엔 좀 쉬어야 다음 주를 버텨요.
돕고 싶은 마음은 있는데 몸이 안 따라줘요.

아내가 아이랑 논다고 하면 자꾸 마음에 안 든다고 해서
차라리 눕게 됐어요.

내가 도움이 안 되는 건 알겠는데
그렇다고 내까지 지칠 필요는 있나 싶고
아내한테는 내 피로가 중요하지 않은 것 같아요

내가 뭘 해줘도 모자란 것 같은데
내 입장도 좀 봐줄 수 있을까요
```

### 예시 2: COUPLE 데이트 비용

**작성자 원글:**
```
1년 동안 거의 제가 다 냈어요
```

**상대방(남친) 시점:**
```
소소한 건 제가 많이 냈거든요.
카페나 마트 같은 거

근데 여자친구는 그걸 잘 기억 못 하는 것 같아서
억울해요

내가 치는 것도 있는데
자꾸 여자친구는 자기가 다 냈다고 생각하는 것 같아요
```

### 예시 3: COUPLE 과거 숨김

**작성자 원글:**
```
전 여친 얘기를 철저히 숨겨요
```

**상대방(남친) 시점:**
```
숨긴다기보다 중요하지 않다고 생각했어요.
과거를 굳이 꺼내봤자 관계에 도움이 안 될 것 같아서요.

내가 신경 안 쓴다고 생각했는데
여자친구는 내가 숨기는 거라고 생각하네요.

내 입장에선 그냥 불필요한 정보일 뿐인데
여자친구는 뭔가 더 깊은 의미가 있는 걸로 받아들이는 것 같음
```

## 스타일 체크리스트

- [ ] 원글의 구체적 사건 최소 1개 이상 언급 (새로운 사건 추가 금지)
- [ ] "나는", "내가" 1인칭으로 감정 표현 (방어가 아닌 감정)
- [ ] 문장 끝 온점(.) 없음
- [ ] 쌍따옴표("") 없음 (간접화법 사용 시 따옴표 제거)
- [ ] 결론·사과·해결책 없음 (혼란·억울함·상처로 끝냄)
- [ ] 상대 비난 아닌 "내가 느끼는 것" 중심
- [ ] 미완성감 유지 (막혀있는 상태 그대로)
