# HAX 컴포넌트 체크리스트 — 다시봄 광장형

> **이 문서의 위치**: [`principles.md`](./principles.md)의 AI 신뢰성 원칙을 **컴포넌트 단위 체크리스트**로 풀어낸 것입니다.  
> PR 리뷰, 새 컴포넌트 작성 시 이 문서를 따라 점검합니다.

> **현재 기준**: 2026-06-02 광장형 피벗 완료.  
> **참고**: Microsoft HAX Toolkit — [Guidelines for Human-AI Interaction](https://www.microsoft.com/en-us/haxtoolkit/ai-guidelines/)

---

## 1. 페이지 레벨 체크리스트

### 피드 페이지 (`/community`)
- [ ] 게스트 열람 가능 (로그인 강제 없음)
- [ ] 무한스크롤 또는 페이지네이션 (카운트다운 표시 금지)
- [ ] 카테고리 필터 (선택 안 함도 가능)

### 사연 작성 (`/community/new`)
- [ ] 로그인 필수 (미로그인 시 로그인 모달로 유도)
- [ ] 관계 카테고리 선택 (A/B 입장 분리 명시)
- [ ] A·B 입장 입력 필드 텍스트카운팅 (제한선 있으면 진행 상태 표시)
- [ ] 발행 단계에서 "상대방이 작성하지 않아도 혼자 발행 가능" 명시

### 사연 상세 (`/community/[id]`)
- [ ] 배심원 카드: "AI 배심원" 레이블 명시
- [ ] 배심원 의견: 판결/처방 표현 없음 ("공감 비율", "작성자 관점" 등으로 재표현)
- [ ] 투표 비율: 실제값만 표시 (임의값 금지)
- [ ] 댓글 섹션: 로그인 미작성 사용자는 댓글 아이콘에 로그인 유도
- [ ] 위기 컨텐츠: CrisisResourceModal 표시 시 닫기 버튼만 가능 (ESC/바깥클릭 차단)

### 알림 (`/notifications`)
- [ ] 배심원 분석 완료 알림에 "AI 배심원의 의견입니다" 표시
- [ ] 읽음 처리 후 30일 자동 삭제 (UX: 명시)

## 2. 코어 컴포넌트 체크리스트

### FeedCard
**역할**: 사연 카드 (피드 목록에 표시)

#### 기본 정보
- [ ] 제목 표시
- [ ] 카테고리 표시
- [ ] 작성자 닉네임 (익명) 표시
- [ ] 날짜/시간 표시

#### AI 신뢰성 (HAX G1, G2, G6)
- [ ] 배심원 요약 있으면 "AI 분석" 레이블 명시
- [ ] 배심원 요약에 판결/처방 표현 없음
- [ ] A측/B측 색상 구분 (초록/붉은) 일관 적용
- [ ] 공감 비율 표시 (실제값만)

#### 접근성
- [ ] `data-testid="feed-card-{id}"` 부착
- [ ] 이모지 하드코딩 없음
- [ ] 금지어 하드코딩 없음 (lint:words 통과)
- [ ] 모바일 반응형

---

### JurorCard
**역할**: 배심원 카드 (상세 페이지에서 9개 배심원 나열)

#### 기본 정보
- [ ] 배심원 이름 (페르소나, 예: "심리상담사 이소윤") 표시
- [ ] 한 줄 소개 표시
- [ ] 프로필 아이콘/아바타 (일관성 있는 스타일)

#### AI 신뢰성 (HAX G1, G6)
- [ ] "AI 배심원" 뱃지·레이블 필수
- [ ] 편향 표시 (A측/B측/중립) 명시
  - A측: 초록 표시
  - B측: 붉은 표시
  - 중립: 회색 표시
- [ ] 의견 본문: 판결/처방 표현 없음
- [ ] 의견 본문: 가정형 톤 ("~처럼 보여요", "~이었을 수 있어요")

#### 인터랙션
- [ ] 클릭 시 의견 전체 펼침 (또는 모달/슬라이드)
- [ ] 닫기: 뒤로 가기 또는 닫기 버튼으로 원상태 복구

#### 접근성
- [ ] `data-testid="juror-card-{juror_id}"` 부착
- [ ] 금지어 하드코딩 없음

---

### JurorPicker
**역할**: 배심원 목록 선택 (관리자 대시보드 등에서 사용할 수 있음)

#### 기본
- [ ] 배심원 리스트 (이름, 소개)
- [ ] 체크박스 또는 선택 상태 표시

#### 접근성
- [ ] `data-testid="juror-picker"` 부착
- [ ] 키보드 네비게이션 가능

---

### VoteBar
**역할**: 투표 비율 시각화

#### 정확성 (HAX G2, G11)
- [ ] A측/B측 비율: 실제 집계값만 표시
- [ ] 백분율 또는 실수치 명시
- [ ] "이 비율은 커뮤니티 투표 결과입니다" 명시 (AI 분석이 아님)

#### 시각화
- [ ] A측: 초록, B측: 붉은 일관 유지
- [ ] 투표 전/후 상태 구분 (아이콘, 색상 짙기 등)
- [ ] 재투표 금지 (이미 투표한 경우 표시)

#### 접근성
- [ ] `data-testid="vote-bar-{post_id}"` 부착
- [ ] 색깔만으로 구분 아님 (숫자·텍스트 라벨도 있음)

---

### CommentBar
**역할**: 댓글 목록 (무한스크롤)

#### 기본
- [ ] 댓글 작성자 닉네임 (익명) 표시
- [ ] 댓글 본문
- [ ] 작성 시간
- [ ] 좋아요 수

#### 안전성
- [ ] 댓글에 금지어 필터 미적용 (사용자 책임)
- [ ] 위기 키워드 있으면 관리자 플래그 (UX: 해당 댓글에 경고 표시 옵션)

#### 접근성
- [ ] `data-testid="comment-{comment_id}"` 부착
- [ ] 무한스크롤: 로딩 상태 명시 (스켈레톤 또는 "더 불러오는 중...")
- [ ] 이모지 하드코딩 없음

---

### CommentComposeSheet
**역할**: 댓글 작성 입력창

#### 기본
- [ ] 로그인 미사용자: 컴포즈 비활성화 + "로그인해주세요" 메시지
- [ ] 로그인 사용자: 입력창 활성화
- [ ] 전송 버튼 ("댓글 게시" 등 명시적 라벨)

#### 안전성
- [ ] 입력 길이 제한 있으면 카운팅 표시 (진행 상태 표시, 타이머 아님)
- [ ] 금지어 필터 미적용 (사용자 입력 책임)
- [ ] 제출 후 입력창 초기화

#### 접근성
- [ ] `data-testid="comment-compose-sheet"` 부착
- [ ] 이모지 추가 버튼 없음 (이모지 금지)

---

### CommunityComment (개별 댓글 컴포넌트)
**역할**: 댓글 단일 항목

#### 기본
- [ ] 작성자 닉네임 (익명) 표시
- [ ] 댓글 본문
- [ ] 작성 시간
- [ ] 좋아요 버튼 (로그인 필요)

#### 안전성
- [ ] 댓글 본문에 판결/처방 표현 있어도 UX에서 필터하지 않음
- [ ] 위기 키워드 표시 (관리자만 보임)

#### 접근성
- [ ] `data-testid="community-comment-{id}"` 부착

---

### UserChip
**역할**: 사용자 정보 칩 (닉네임, 권한 표시)

#### 기본
- [ ] 닉네임 표시
- [ ] 권한 레이블 (예: "작성자") 있으면 표시
- [ ] 아바타 (있으면)

#### 접근성
- [ ] `data-testid="user-chip-{user_id}"` 부착

---

### BrandBar
**역할**: 앱 헤더/네비게이션

#### 기본
- [ ] 로고 표시
- [ ] 메인 네비게이션 (피드, 알림, 프로필 등)
- [ ] 로그인/로그아웃 버튼

#### 안전성
- [ ] 위기 상황 핫라인 링크 (상시 표시, 관리자 설정 시 강조)

#### 접근성
- [ ] 모든 네비 버튼: `data-testid` 부착
- [ ] 키보드 포커스 가능

---

### SideStory
**역할**: 사이드 패널 또는 추가 정보 카드

#### 기본
- [ ] 컨텐츠 명확한 라벨 ("배심원 정보", "위기 자원" 등)

#### AI 신뢰성 (해당 시)
- [ ] AI 생성 컨텐츠면 "AI가 분석한 결과입니다" 명시

#### 접근성
- [ ] 닫기 버튼 명시 (모바일에서 스와이프/뒤로가기)

## 3. 상황별 체크리스트

### 위기 컨텐츠 처리
- [ ] CrisisResourceModal 표시 (관리자 crisis flag 또는 키워드 자동 감지 시)
- [ ] 핫라인 번호 정확 (1366, 1393, 132 등)
- [ ] 닫기: 명시적 버튼만 (ESC/바깥클릭 차단 의도적)
- [ ] 라이선스: 외부 자원 링크 (클릭 후 외부로 이동)

### 색상 일관성
- [ ] A측 (작성자): 초록 계열 (`var(--P-a)` 또는 커스텀 초록)
- [ ] B측 (상대방): 붉은 계열 (`var(--P-b)` 또는 커스텀 붉은)
- [ ] 중립 (커뮤니티): 회색 계열
- [ ] 초록/붉은을 A/B 이외의 의미로 사용 금지

### 필터 미적용 원칙
- [ ] 사용자가 입력한 텍스트: 금지어 필터 미적용
- [ ] AI가 생성한 텍스트: 금지어 검사 + 판결/처방 표현 제거

### 데이터 속성 (e2e 테스트)
- [ ] 모든 주요 상호작용 요소: `data-testid` 부착
- [ ] 변경 시 `tests/e2e-realbe/support/selectors.ts` 동기화 필수
