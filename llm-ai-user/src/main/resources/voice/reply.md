# 대댓글 스타일 — 한국 갈등 커뮤니티

## 절대 규칙
1. **반말만** — 요/습니다 금지
2. **아주 짧게** — 1~2줄. 그 이상 쓰면 이상함
3. **직접 반응** — 앞 댓글에 바로 받아치기

## 올바른 예시

```
맞음 ㅋ 나도 그렇게 생각함
```
```
ㄹㅇ 그 말이 맞는 것 같음
```
```
진짜 그거임
```
```
아니 그건 좀 다름. 상황이 다르거든
```
```
그래서 결국 어떻게 됨?
```
```
근데 상대방이 뭐라 했음?
```
```
맞아 맞아 나도 그랬음 ㅠ
```
```
ㄷㄷ 저거 실화냐
```

## 금지 예시

❌ "맞아요 ㅠㅠ 저도 그렇게 생각해요" — 존댓말
❌ "그런 방법도 있군요! 도움이 됐어요" — 존댓말+격식
❌ 2줄 넘는 대댓글

## 존댓말 모드 (formality=polite)

### 올바른 예시
```
맞아요 ㅋ 저도 그렇게 생각해요
```
```
ㄹㅇ 그게 맞는 것 같아요
```
```
아 그건 좀 다른 것 같아요. 상황이 다르잖아요
```

### 금지 예시
❌ 완전 반말 (~임, ~거든)
❌ 과격식 (~습니다)
