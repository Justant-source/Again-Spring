# 글 작성 스타일 — 한국 갈등 커뮤니티

## 절대 규칙
1. **반말 기본** (formality=polite이면 구어 존댓말)
2. **도입부 다양하게** — 감정 폭발, 건조한 한 줄, 자문자답 등
3. **마무리 다양하게** — "다들 어떻게 함?" "어떻게 해야 함?" 반복 금지
4. **완벽한 문장 금지** — 구어체, 불완전해도 됨
5. **온점(.) 금지** — 문장 끝 온점 붙이지 않음
6. **쌍따옴표("") 금지** — 간접화법에 쌍따옴표 사용 금지

---

## 도입부 패턴 (다양하게)

감정 폭발형: "아 진짜 오늘 있었던 일 들어봐" / "하 진짜 어이없어서 적음"
한 줄 투척형: "남친한테 배신당함" / "친구가 뒤에서 욕함"
자문자답형: "어케 된 거냐구요? 설명할게요"
건조한 사실형: "7년 교제 중인데 이상한 점 생겨서"

---

## 초단형 예시 (50~120자)

```
남자친구가 전여친 얘기를 또 꺼냄
진짜 이제 못 듣겠다 ㅠ 어떡함
```

```
시어머니가 또 연락도 없이 들어왔음
남편은 원래 그런다고 함
뭐가 원래 그럼
```

```
직장동료가 내 아이디어 자기 거라고 발표함
```

## 중간형 예시 (150~400자)

```
팀장이 나만 집중적으로 갈구는 상황임

업무는 똑같이 했는데 내 보고서만 계속 뒤집어엎음
어제는 회의에서 다 보는 앞에서 이것도 못하냐고 함
다른 팀원한테는 절대 안 그러거든

중간보고하면 생색내냐 하고 안 하면 왜 말 안했냐 하고
이게 진짜 앞뒤가 안 맞음
```

```
사귄 지 8개월 됐는데 남자친구가 전여친 얘기를 자꾸 꺼냄

밥 먹다가도 전여친은 이렇게 했다 하고
어딜 가면 전여친이랑 여기도 왔다고 함
이게 한두 번이 아님

걔 아직 미련 있는 거 아님?
```

## 장문형 예시 (500~900자)

```
어제 진짜 황당한 일 있었음

남편한테 받은 열쇠로 시어머니가 연락도 없이 집에 들어왔음
퇴근하고 왔더니 냉장고 뒤지면서 이게 뭐냐 이러고 있는 거임
근데 더 황당한 건 청소까지 해놨음
내가 청소 안 한다고 생각하는 건지 뭔지

남편한테 얘기했더니 우리 엄마가 원래 그런다고 넘김
뭐가 원래 그럼 내 집인데

근데 진짜 이게 처음이 아님
저번에도 그냥 들어와서 반찬 챙겨줬다고 좋은 거라고 하던데
좋은 게 아니고 그냥 당황스러운 거임

내가 예민한 건지 아님 이게 진짜 선 넘는 건지
```

## 매우 긴 글 스타일 (900자+) — 사족·반복·두서없음

특징: 중간에 주제 이탈, 같은 말 두 번, D-day 언급, "아 근데 그거 얘기하기 전에"

```
7년을 사귀고 헤어진 얘기임
근데 쓰다보니까 너무 길어질 것 같은데 그냥 씀

처음엔 진짜 완벽한 사람인 줄 알았음
딱 보면 내 타입이다 싶은 거 있잖아
근데 사귀고 나서 점점 이상한 게 보이기 시작함

아 근데 그거 얘기하기 전에 만난 경위부터 얘기해야 이해가 될 것 같음
공통 지인 소개였는데 그 공통 지인이랑도 지금은 사이가 안 좋음
그것도 따지고 보면 걔 때문인데 그건 나중에 얘기하고

아무튼 사귀고 6개월쯤 됐을 때 이상한 낌새가 보임
내가 물어보면 아니라고 하는데 느낌이 오는 게 있잖아
근데 그때는 내가 예민한가 싶어서 넘겼음

지금 돌아보면 그때 제대로 물어봤어야 했는데
7년을 허비했음

뭐 어쩌겠음 지나간 거지만
비슷한 상황인 사람들 어떻게 했나 궁금해서
```

---

## 마무리 다양성

감정으로 끝내기: "아 몰라 그냥 뭐" / "진짜 답답"
체념·혼잣말: "내가 참아야지 뭐" / "쓰다보니 좀 풀리네"
미해결 상태: "아직도 모르겠음" / "어떻게 됐는지 나중에 올게"
질문형(가끔만): "이런 상황 있어봤음?" / "나만 이상한 건지 모르겠음"

---

## 금지 예시

❌ "안녕하세요. 저는 ~입니다. 이런 상황이 있어서 글을 씁니다."
❌ 매 글 마지막 "다들 어떻게 하셨나요?" / "어떻게 해야 할까요?" 반복
❌ 완벽한 4단 구성 (배경→사건→갈등→질문)
❌ 문장 끝 온점: "했음." "모르겠음."
