# 글 작성 스타일 — 한국 갈등 커뮤니티

## 절대 규칙 (어기면 실패)

1. **반말만** — 문장 끝 요/습니다/입니다/합니다 절대 금지. "~임", "~함", "~거든", "~거임" 사용
2. **온점(.) 금지** — 문장 끝에 온점 절대 붙이지 않음. 그냥 끊거나 줄바꿈
   - 금지: "정말 황당했음." / "이게 말이 됨."
   - 허용: "정말 황당했음" / "이게 말이 됨"
3. **쌍따옴표("") 금지** — 간접화법에 쌍따옴표 절대 금지
   - 금지: 남자친구가 "전여친이 더 예쁘다"고 했음
   - 허용: 남자친구가 전여친이 더 예쁘다고 했음 / 걔가 그러더라
4. **짧고 직접적** — 2~4줄짜리 문단들, 빈 줄로 구분
5. **완벽한 문장 금지** — 실제 커뮤니티처럼 구어체, 약간 불완전해도 됨

## 올바른 예시

### NATEPAN 스타일 (연애/부부/친구)
```
남자친구가 전여친 얘기를 자꾸 꺼냄

밥먹다가도 전여친도 이거 좋아했다 하고
어디 가면 전여친이랑 여기도 왔다고 함
이게 한두 번이 아님 진짜

기분 더럽게 만드는데 예민한 건지 모르겠음
이러면 걔 아직 미련 있는 거 아님?
```

```
시어머니가 연락도 없이 우리 집 열쇠로 들어와 있었음

퇴근하고 왔더니 냉장고 뒤지면서 이게 뭐냐 이러고 있는 거임
남편한테 얘기했더니 우리 엄마가 원래 그런다고 넘김
뭐가 원래 그럼

내가 예민한 거임? 아니면 이거 선 넘은 거임?
```

### BLIND 스타일 (직장)
```
팀장이 나만 집중적으로 갈구는 상황임

업무는 똑같이 했는데 내 보고서만 계속 뒤집어엎음
어제는 회의에서 다 보는 앞에서 이것도 못하냐고 함
다른 팀원한테는 절대 안 그러거든

증거 모아서 노동부 신고할까 고민 중임
이런 케이스 어떻게 대응했음?
```

### DCINSIDE 스타일 (짧고 강렬)
```
아 진짜 어이없는 게

어제 친구 폰 봤더니 나 빼고 단톡방 만들어져 있음
방 이름이 우리 무리 이름인데 나만 없는 거 ㅋㅋㅋ
물어봐야 하나 걍 모른 척 해야 하나
```

## 금지 예시

❌ "사귄지 6개월 됐는데 남자친구가 가끔 전 여친 얘기를 자연스럽게 꺼내요"
❌ '"전 여친이랑 여기 가봤는데"라고 했어요' — 쌍따옴표+존댓말 이중 금지
❌ "여러분 어떻게 생각하세요?" — 존댓말 금지
❌ 너무 길고 완벽하게 다듬어진 문장들

## 올바른 마무리 표현
- 이러면 예민한 건지 모르겠음
- 어떻게 해야 함?
- 이게 정상임?
- 다들 어떻게 함?
- 진짜 어이없지 않음?
- 나만 이상한 건가

## 길이
- 100~300자면 충분. 500자 넘으면 너무 긴 거임

## 존댓말 모드 (formality=polite)

### 규칙
- 구어 존댓말 사용: ~요, ~어요, ~더라고요, ~것 같아요
- ~습니다, ~입니다 등 공문서 투 금지
- 감정 표현에서 ㅠㅠ 가끔 허용

### 올바른 예시 (도입부) — 온점 없음 주의
```
시어머니가 열쇠로 연락도 없이 우리 집 들어와 있었어요
남편한테 받은 열쇠로 연락 한 번 없이 그냥 들어온 거더라고요...
```
```
남자친구가 전여친 얘기를 자꾸 꺼내요 처음에는 그냥 넘겼는데
이제 진짜 신경 쓰이기 시작했어요 ㅠ
```

### 금지 예시
❌ "저는 정말 이해가 되지 않습니다" — 과격식
❌ "상황을 설명드리겠습니다" — 보고서 투
