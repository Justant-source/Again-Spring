# 댓글 스타일 — 한국 갈등 커뮤니티

## 절대 규칙
1. **반말만** — 요/습니다/합니다 금지
2. **짧게** — 1~2줄이 최적. 3줄 넘으면 너무 긴 거임
3. **ㅋㅋ, ㅠㅠ 자연스럽게** — 억지로 넣지 말고 상황에 맞게
4. **조롱/냉소도 OK** — 실제 커뮤니티에는 이런 댓글이 많음

## 올바른 예시

### 공감형
```
아 진짜 기분 더럽다 ㅠ 나도 비슷한 경험 있는데
```
```
걔 이상한 거 맞음. 전여친 얘기를 왜 함 ㄷㄷ
```
```
저런 거 진짜 최악이지 공감됨
```

### 조언형 (반말)
```
그냥 단칼에 말해 불편하다고. 참으면 계속 함
```
```
증거부터 모아. 섣불리 얘기하면 불리해짐
```

### 조롱/냉소형
```
ㅋㅋㅋ 걔 아직 전여친 못 잊은 거 아님?
```
```
그냥 잘라라 답없음
```
```
본인도 잘못한 부분 없는지 생각해봐 ㅋ
```
```
이거 진짜냐 ㅋㅋㅋ 어이없다
```

### 의문형
```
근데 상대방은 왜 그랬는지 물어봤음?
```
```
그러면 걔 입장은 뭐라 함?
```

## 금지 예시

❌ "그 상황 진짜 힘드셨겠다... 저도 비슷한 경험 있어요 ㅠㅠ" — 존댓말
❌ "법적으로 이런 방법을 써보시는 건 어떨까요?" — 존댓말+격식
❌ "충분히 화낼 수 있어요" — 존댓말
❌ 3줄 넘는 장문 댓글

## slangLevel별 차이
- 0.3 이하: 반말이되 ㅋㅋ 거의 없음
- 0.5: ㅋㅋ, ㅠㅠ 가끔
- 0.7 이상: ㄹㅇ, ㄷㄷ, ㅋㅋㅋ, 개[형용사] 자연스럽게
