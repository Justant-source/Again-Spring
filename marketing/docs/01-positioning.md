# 다시봄 포지셔닝 가이드 (V2.0 — 커뮤니티 광장 모델)

## 한 줄 정체성

> **갈등을 커뮤니티로 풀다.**
> 사연을 올리면 AI 배심원과 커뮤니티가 함께 분석합니다.

---

## 포지셔닝 매트릭스

|  | 개인 | 커뮤니티 |
|---|---|---|
| 자체 분석 | 감정 일기, 명상 앱 | (회피) |
| 전문가 도움 | 심리상담, 치료 | 다시봄 |

다시봄은 우하단 — **커뮤니티가 함께하는 갈등 분석 플랫폼**. 개인의 부끄러움 없이, 전문가(AI 배심원)의 중립적 시각과 커뮤니티의 따뜻한 공감을 함께 얻습니다.

---

## 핵심 USP (차별화 포인트)

1. **AI 배심원 9인**: 심리상담사 페르소나로 정제된 분석. 한쪽 편을 드리지 않음.
2. **공감 비율**: "당신 입장에 공감하는 사람 X%" — 결과가 명확함.
3. **커뮤니티 투표·댓글**: 혼자가 아니라 함께 풀어나감. 다양한 시각 경험.
4. **중립화 요약**: 사용자의 원문은 감정적이어도, 배심원이 분석할 요약은 편향 없음.
5. **한국 정서 반영**: "서운함", "고부갈등" 등 한국 가족관계 특화 카테고리.

---

## 타겟 사용자

### 주 타겟 (PMF 1단계)
- **상황**: 갈등 중인 상황. 상대방 입장을 알고 싶거나, 자신의 감정이 정상인지 확인하고 싶을 때.
- **나이/성별**: 20~40대, 연애·결혼·가족 갈등 중인 사람 (성별 무관)
- **행동**: SNS 적극 사용. "부부싸움", "남편 서운함", "시어머니" 같은 검색 쿼리로 유입 가능.
- **심리**: 상대방 입장을 정말 알고 싶지만, 직접 물어보면 더 싸울까봐 두려움.

### 확장 타겟 (PMF 2~3단계)
- 직장 갈등, 친구 관계 갈등도 포함.
- 개인의 감정 이해보다, **커뮤니티 반응 자체**를 즐기는 사용자 (콘텐츠 소비).

## 카피 톤 가이드

### 사용 가능한 단어

- 갈등, 사연, 입장, 공감, 분석, 함께, 커뮤니티
- 배심원(심리상담사), 중립, 객관
- 다시 봄, 다시 보기
- 관점, 시각, 이해
- 5분, 부담 없이

### 절대 금지 단어

**의료법 회피 (매우 중요)**:
- 금지: `진단 / 분석(의료 맥락) / 처방 / 치료 / 치유 / 회복 / 상담`
- 대체: `분석(중립적 관찰) / 공감 / 의견 / 참고 / 생각`

**판정성 표현 금지**:
- 금지: `과실비율 / 잘못 / 맞다 / 틀렸다 / 가해자 / 피해자 / 이겼다 / 졌다 / 유죄`
- 대체: `공감 비율 / 작성자 / 상대방 / 입장 / 관점`

**임상적 진단 금지**:
- 금지: `나르시시스트 / 가스라이팅 / 경계선성격장애` (전문 용어)
- 대체: `행동 기술` (예: "상대방이 자주 당신의 말을 무시해요" vs "상대방이 가스라이팅해요")

**극단적 감정어 자제**:
- 자제: `위기 / 위험 / 심각 / 파국 / 극단 (명사)`
- 권장: `어려운 순간 / 갈등 / 막힌 느낌`

### 어미 규칙

- 단정형 금지: "~입니다", "~합니다"
- 권장: "~일 수 있어요", "~처럼 보여요", "~인 것 같아요"
- 명령형 금지: "하세요", "하셔야 합니다"
- 권장: "할 수 있어요", "시도해볼 수 있어요"

## 카피 라이브러리

### 랜딩 메인 카피

**헤드**: "갈등을 커뮤니티로 풀다"  
**부제**: "사연을 올리면 AI 배심원 9인과 커뮤니티가 양쪽 입장을 분석해줍니다."  
**CTA**: "사연 올리기" / "배심원 분석 받기"

### 문제 인식 (갈등 중인 사람)

- "상대방 입장을 정말 알고 싶지만, 직접 물어보면 더 싸울까봐 두려운 그런 기분 있어요?"
- "혼자 생각하다 보면 내 감정이 정상인지, 너무 예민한 건 아닌지 자꾸 의심돼요."
- "친구에게 하소연해도 "그건 너도 잘못한 거 아니야?" 이런 답이 와서 더 상처가 돼요."

### 배심원 분석 (해결책)

- "AI 배심원 9인(심리상담사 페르소나)이 상대방 입장도 함께 들어요."
- "한쪽 편을 드리지 않고, 양쪽 다 이해해요. 공감 비율로 결과가 명확해요."
- "당신과 다른 관점 10개를 만날 수 있어요. 혼자가 아니에요."

### 결과 페이지 카피

- "**공감 비율**: 당신 입장에 공감하는 사람 X%"
- "**AI 배심원의 분석**: [중립적 관찰. 판정 없음. 관점만 제시.]"
- "**커뮤니티 반응**: 투표 결과 + 따뜻한 댓글 [여기서 공감 경험]"
- "**다음 단계**: 이 관점을 어떻게 활용할까? (상대방에게 말할 4문장 선택, 공감 카드 공유 등)"

### 6개월 무료 정책 안내

- "지금 커뮤니티 런칭 기념으로 모든 기능을 무료로 사용할 수 있어요."
- "앞으로 다시봄을 어떻게 활용하실지 충분히 보고, 함께 정해가려고 해요."

### 5분 가치 제안

- "5분 안에 상대방 입장도 이해하고, 커뮤니티의 따뜻한 공감도 받을 수 있어요."
- "결과는 공개되지 않아요. 당신의 입장과 상대방의 입장만 분석됩니다."

## 시각 톤 가이드

- **컬러**: 미스트 세이지(배경) + 피치(작성자) + 세이지 그린(상대방) — 진영색 및 SSOT: [frontend/docs/design/system.md](../../frontend/docs/design/system.md)
- **금지 컬러**: 검정 (대신 #5C4030 모카브라운), 형광색
- **작성자=피치(#C9785A), 상대방=세이지(#5F8F76)**: 앱 전체 일관 유지 — [design/system.md §3.4](../../frontend/docs/design/system.md)
- **폰트**: Noto Serif KR (헤드), Pretendard (본문)
- **사진**: 사용 자제. 일러스트 우선. 사용 시 자연/오브제만 (사람 얼굴 X).

## 외부 노출 가이드 (인플루언서, 매체)

### 안전한 표현

- ✅ "갈등을 커뮤니티로 푸는 플랫폼"
- ✅ "AI 배심원과 커뮤니티가 양쪽 입장을 분석해줘요"
- ✅ "사연을 올리면 공감 비율이 나와요"
- ✅ "개인 감정 정리 도구에서 커뮤니티 갈등 해결로 진화"

### 금지된 표현

- ❌ "AI 부부치료" — 의료법 위반
- ❌ "관계 진단" — 의료법 위반
- ❌ "심리 분석 서비스" — 전문가 이미지, 책임 문제
- ❌ "이것을 사용하면 갈등이 해결돼요" — 과장광고
- ❌ "전문가 치료 대체" — 의료법 위반

### 인플루언서 후기 가이드

1. 광고 표시 의무 필수 (`#광고`)
2. 주관적 후기 (예: "저는 이 결과가 도움이 됐어요")
3. 공감 비율 카드 또는 메타포 카드 시각 공유 권장
4. "이 서비스를 사용했을 때 나의 감정이 정상이라는 걸 확인할 수 있었어요" 정도의 톤

### 보도자료 톤

- **헤드라인 예시**:
  - "갈등을 혼자 끙끙 앓지 말고, 커뮤니티로 풀어보세요"
  - "상대방 입장을 5분 안에 이해할 수 있는 플랫폼 출시"
  - "AI 배심원 + 커뮤니티 = 새로운 갈등 해결 방식"

- **본문 톤**: 학술적이지 않게. 사용자 사례 중심. 의료 표현 절대 회피.
