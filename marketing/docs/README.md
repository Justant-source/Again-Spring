# 다시봄 마케팅 문서 폴더 (`marketing/docs/`)

이 폴더는 다시봄의 포지셔닝, 페르소나, 로드맵, 바이럴 메커니즘, 콘텐츠 캘린더를 한곳에 모은 마케팅 전략 single source of truth입니다.

> 상위 `marketing/`에는 이 전략 문서(`docs/`) 외에 이미지 렌더링 사이드카(`renderer/`)와 소셜 자동 포스팅 사이드카(`social-poster/`)가 함께 있습니다. 디렉토리 개요는 [`../README.md`](../README.md) 참조.

| `05-content-calendar.md` | 블로그 글 10편 outline + 포스팅 일정 | 월간 |

## 사용 방법

- 신규 마케팅 액션을 만들 때 본 문서들을 먼저 확인 (톤 일치)
- 외부 협력사·인플루언서에게 톤 가이드 공유 시 본 문서 발췌 사용
- 모든 카피/슬로건 변경은 `01-positioning.md`에서 시작
