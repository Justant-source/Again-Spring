# 다시봄 페르소나 (V1.5)

## 1차 타겟 (PMF 핵심)

### 김서영 (28세, 마케팅 회사 대리, 동거 2년차)

#### 인구통계
- 서울 거주, 4년제 졸업, 소득 3~4천만원
- 인스타그램·카카오톡 일상 사용
- "감정 일기" 같은 기록 앱에 호의적

#### 갈등 상황
- 남자친구와 시가 명절 분담 문제로 격주로 다툼
- 카카오톡으로 "그게 어떻게 그래?" 같은 짧은 답이 와서 더 답답
- 친구한테 하소연하면 "그건 네가 너무 예민해" 같은 답을 듣고 또 상처
- 야근 중 화장실 갔다 와서 "내가 또 뭐라고 했길래" 곱씹는 타입

#### 다시봄을 발견하는 경로
- 인스타그램 인플루언서 후기
- 카카오톡 공유 카드 (친구가 보낸 메타포 카드)
- "남편한테 서운하다" 검색 → 블로그 SEO

#### 사용 시나리오
- 싸운 직후 화장실에서 사연 작성
- 자기 전 침대에서 배심원 분석 결과 확인
- 출근길 지하철에서 커뮤니티 투표·댓글 읽기

#### 다시봄에서 얻고 싶은 가치
1. "내 감정이 정상이라는 확인" (1차 욕구) — 공감 비율로 명확히
2. "상대방도 그럴 만한 이유가 있었구나" (2차 욕구) — 배심원 분석으로 이해
3. "혼자가 아니라 커뮤니티 같은 느낌" (심리적 가치) — 투표·댓글의 따뜻함

#### 사용 후 행동
- 메타포 카드 + 공감 비율 카드를 인스타 스토리에 공유 (자신의 경험 표현)
- 친구에게 카톡으로 "다시봄에서 나 입장이 X% 나왔어"라고 공유
- 댓글로 다른 사람의 사연에 공감 의견 달기
- 며칠 후 재방문 (다른 갈등 발생 시, 또는 재미 목적)

## 2차 타겟 (확장)

### 박지훈 (35세, IT 회사 차장, 결혼 5년차, 자녀 1명)

#### 인구통계
- 경기 거주, 소득 5~7천만원
- 인스타그램은 가끔, 카카오톡 메인

#### 갈등 상황
- 아내와 양육관 차이 (스마트폰 노출, 학원 결정)
- 본인 부모님과의 거리감 (효도 의무감)
- 직장 스트레스로 집에서 무뚝뚝해짐

#### 다시봄을 발견하는 경로
- 1차 페르소나(김서영) 같은 사람의 입소문
- 30대 부부 블로그 SEO
- 카카오톡 알림톡 (V1.6 이후)

#### 사용 시나리오
- 출근 전 카페에서 아내의 입장 분석 읽기
- 아내가 "다시봄의 배심원이 뭐래?" 묻고, 함께 결과 토론
- 늦은 저녁에 배심원 분석으로 아내의 마음 이해하기

#### 다시봄에서 얻고 싶은 가치
1. "내가 아내와의 관계에서 어디서 막혀있는지 객관적 관찰"
2. "아내 입장도 이해할 수 있는 구체적인 배경"
3. "커뮤니티 댓글을 통한 다양한 관점 학습"

## 3차 타겟 (장기)

### 이수민 (24세, 대학원생, 연인 1년차)

#### 인구통계
- 서울 거주, 학생, 인스타그램·트위터·디스코드
- MBTI에 익숙, 자기참조 콘텐츠 좋아함

#### 갈등 상황
- 남자친구와 연락 빈도, 데이트 횟수 갈등
- 친구 관계의 미묘한 거리감

#### 사용 시나리오
- 침대에서 트위터 보다가 발견 (SEO 또는 인플루언서 후기)
- 친구가 보낸 메타포 카드 + 공감 비율 보며 호기심으로 진입
- 댓글로 재미있는 의견 달기, 커뮤니티 분위기 즐기기

#### 가치
1. "내 패턴과 감정을 MBTI처럼 메타포로 표현" (자기참조)
2. "메타포 카드 + 공감 비율의 시각적 재미"
3. "커뮤니티 댓글에서 다양한 의견·위로 받기"
4. "다른 사람 사연에 댓글 달기 (공감 표현, 의견 제시)"
