# 다시봄 바이럴 메커니즘 (V2.0 커뮤니티 광장)

## 4종 공유 카드 매핑

| Variant | 파일 | 사용 시나리오 | 바이럴 강도 |
|---|---|---|---|
| **B (블러된 4문장)** | `card-b-blurred-letter.svg` | 카카오톡 친구 공유 — "이게 뭐야?" 호기심 유발 | ⭐⭐⭐ |
| **C (메타포 카드)** | `card-c-metaphor-frame.svg` | 인스타 스토리 — MBTI식 자기참조 + 감정 표현 | ⭐⭐⭐⭐⭐ |
| **D (공감 비율)** | `card-d-empathy-ratio.svg` | 모든 채널 — "당신 입장 X%, 상대방 입장 Y%" 시각화 | ⭐⭐⭐⭐ |
| **E (배심원 분석 하이라이트)** | `card-e-jury-highlight.svg` | 인스타 + 카톡 — "배심원이 주목한 포인트" | ⭐⭐⭐ |

**C variant (메타포)가 최강**: MBTI처럼 자기참조 + 미적 통일성 + 호기심 유발.  
**D variant (공감 비율)가 신규**: 커뮤니티 광장 모델에서 핵심 결과물. "객관적 수치" + "내 입장이 얼마나 공감받는가" 시각화.

## 12종 메타포 ↔ 4 Horsemen 패턴 매핑

LLM이 사용자의 발화를 분석한 후, 4 Horsemen 점수 분포에 따라 메타포 자동 선택:

| 메타포 | 활성화 조건 |
|---|---|
| 잠겨있는 우체통 | 담쌓기 ≥ 6 + 회복 시도 부족 |
| 끓는 주전자 | 비난 ≥ 6 + 격화 기여 ≥ 5 |
| 걸어 잠근 문 | 담쌓기 ≥ 7 + Bid 응답률 < 30% |
| 너무 큰 우산 | 방어 ≥ 5 + 조망수용 부족 |
| 비 맞는 사람 | Bid 응답률 < 20% (오래 무시당함) |
| 얼어붙은 연못 | 담쌓기 ≥ 5 + 4 Horsemen 전반 낮음 |
| 금 간 유리창 | 모든 점수 중간 + 격화 기여 ≥ 4 |
| 빈 의자 | 담쌓기 ≥ 6 + 묵힌 서운함 카테고리 |
| 넘치는 컵 | 비난 + 경멸 합 ≥ 8 |
| 흔들리는 다리 | 회복 시도 보임 + 격화 기여 중간 |
| 반쯤 열린 편지 | 회복 시도 ≥ 3 + Bid 시도 발견 |
| 뿌리 얽힌 두 나무 | 모든 점수 낮음 + Repair 자주 시도 |

매핑 알고리즘 구현: `backend/src/main/java/.../service/report/MetaphorSelector.java` (V1.5 신규)

## 공유 카드 사용 흐름

### 인스타그램 스토리 (C variant 메인)

1. 사용자가 결과 페이지에서 "공유" 버튼
2. 카드 선택 화면: C (메타포) / D (공감 비율) / E (배심원 하이라이트) 중 선택
3. "인스타 스토리에 공유" 버튼 클릭
4. 인스타그램 앱 자동 실행, 카드가 스티커로 삽입됨
5. 사용자가 캡션 추가 (예: "내 감정이 X%에 공감받았어요") 후 게시
6. 친구들이 보고 "다시봄"으로 검색 또는 프로필 링크 클릭

### 카카오톡 (B variant + D variant 혼합)

1. 사용자가 결과 페이지에서 "공유" 버튼
2. "블러된 4문장" (B) 또는 "공감 비율" (D) 중 선택
3. "카톡으로 보내기" 버튼 클릭
4. 카카오톡 자동 실행, 친구 선택
5. 카드 + 다시봄 링크 자동 삽입
6. 친구가 카드 미리보기 → 호기심으로 클릭 → 다시봄 진입

### 커뮤니티 내부 (댓글 공유)

1. 다른 사용자의 사연을 읽고 "흥미로워" → 댓글에서 D variant (공감 비율) 요약 공유
2. "내 입장도 당신처럼 X% 공감받았어"라며 카드 첨부
3. 댓글의 카드를 본 방문자들이 클릭 → 사용 의욕 증대

## 바이럴 KPI 측정

각 카드 variant별:
- 노출 수 (impression)
- 외부 도메인으로의 referrer 발생 수
- og:image 호출 수 (카카오 미리보기 = 잠재적 클릭)
- 그 카드를 본 후 가입한 사람 수 (UTM 파라미터)

## 부정 바이럴 방어 장치

### 극단 비율 (80% 이상) 공유 차단

D variant (공감 비율)에서 한쪽이 80% 이상이면:
- 카드 자체에 비율 숫자 노출 X (막대만 시각적으로 표시, 구체 수치 생략)
- 카드 하단 문구를 다음으로 자동 변경:
  > "이 결과는 특수한 상황의 참고용이에요. 일반화하기 어려워요."
- 커뮤니티 투표/댓글 기능은 정상 활성 (수치 은폐만, 토론은 허용)

구현: `frontend/components/result/ShareCardRatio.tsx` 내부 가드 적용됨.

### 워터마크 (모든 공유 카드)

모든 공유 카드 우하단에 작게 다음 텍스트:
> "이 결과는 다시봄의 AI 배심원 분석이에요. 참고용입니다."

목적:
- "AI가 날 판결했다"는 오해 방지
- 캡처 후 무분별한 확산 차단
- 책임 소재 명확화

### 커뮤니티 댓글 모니터링

- 혐오·비난 표현 자동 필터링
- "이 입장이 옳다/틀렸다" 같은 판정적 댓글 경고
- 반복 위반 사용자 일시 정지
