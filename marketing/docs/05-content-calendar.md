# 다시봄 콘텐츠 캘린더 (Day 60~90 발행)

## 시드 글 10편 outline

### Day 60: "남편한테 서운하다고 말하면 왜 더 멀어질까"

- 키워드: 남편 서운함, 부부 대화 단절
- 구조: 사례 → Gottman 4 Horsemen 도입 (학술명 X, "4가지 표현" 정도) → 다시봄 배심원 분석으로 보는 상대방 입장
- CTA: "5분이면 상대방 입장도 이해할 수 있어요"
- 타겟 페르소나: 김서영
- 분량: 2,000~2,500자

### Day 63: "시어머니랑 다툰 다음 날, 가장 먼저 해야 할 일"

- 키워드: 시댁 갈등, 고부갈등 대처
- 구조: 한국 부부의 시댁 갈등 통계 → 한국 고유 카테고리 4종 안내 (다시봄 카테고리 매핑) → 배심원 분석으로 다양한 입장 이해하기
- CTA: "다시봄에서 시댁 사연의 배심원 분석을 보세요. 예상 밖의 관점을 찾을 거예요"
- 타겟 페르소나: 김서영
- 분량: 2,000자

### Day 66: "부부싸움 후 카톡 답장이 늦을 때, 진짜 의미"

- 키워드: 부부싸움 후 침묵, stonewalling
- 구조: stonewalling의 한국적 발현 → 메타포 (잠겨있는 우체통, 걸어 잠근 문) → 배심원 분석: 상대방은 왜 침묵했을까?
- CTA: "다시봄에서 같은 상황의 여러 사연을 보세요. 침묵 뒤의 진짜 이유가 있어요"
- 타겟 페르소나: 김서영
- 분량: 1,800자

### Day 69: "감정 일기를 5년 써본 사람이 알려주는 3가지"

- 키워드: 감정 일기, 마음 정리법
- 구조: 감정 일기의 한계 (혼자만의 생각) → 다시봄의 차별점 (배심원 분석 + 커뮤니티 의견 = 객관화)
- CTA: "혼자 곱씹던 마음을 다시봄에서 다양한 시각으로 봐보세요"
- 타겟 페르소나: 이수민, 김서영
- 분량: 2,200자

### Day 72: "이혼하기 전, 마지막으로 해보면 좋을 5분"

- 키워드: 이혼 전 부부 대화, 부부 이해
- 구조: 이혼 직전 단계의 4가지 신호 → "배심원 분석으로 상대방 마음을 마지막으로 이해해보세요"
- CTA: 다시봄에서 상대방 입장을 배심원 분석으로 읽어보세요
- ⚠️ 주의: 의료법 회피. "치료", "부부치료" 표현 절대 금지. "대화", "이해" 사용.
- 분량: 2,000자

### Day 75: "친구한테 하소연했다가 더 화난 적 있나요"

- 키워드: 하소연, 친구 위로, 공감
- 구조: 친구 위로의 한계 (한쪽 편 제시) → 다시봄 배심원 분석 (중립적 관점 + 다양한 커뮤니티 의견)
- CTA: "다시봄에서 한쪽 편 없이 당신의 상황을 바라보세요"
- 타겟 페르소나: 이수민, 김서영
- 분량: 1,800자

### Day 78: "상대방이 '미안해'라고 못하는 진짜 이유"

- 키워드: 사과 못하기, 자존심, 관계 회복
- 구조: 사과의 심리적 메커니즘 → 배심원 분석으로 상대방의 입장 이해 → 대화 시작점 찾기
- CTA: 다시봄에서 배심원과 커뮤니티의 다양한 관점 보기
- ⚠️ 성별 단정 톤 주의 — "남편이" 아닌 "상대방이" 중심. 보편적 메커니즘 강조.
- 분량: 2,000자

### Day 81: "부부싸움이 끝난 척 끝나지 않는 이유"

- 키워드: 묵힌 서운함, 부부 갈등 누적
- 구조: 한국 고유 카테고리 "묵힌 서운함" 소개 → Gottman의 negative sentiment override → 배심원 분석으로 누적된 감정 풀어내기
- CTA: 다시봄의 "묵힌 서운함" 카테고리에서 배심원과 커뮤니티와 함께 풀어보세요
- 분량: 2,200자

### Day 84: "가트만 박사가 말하는, 이혼 직전 부부의 4가지 표현"

- 키워드: Gottman 가트만 4 Horsemen
- 구조: 학술적 정확성 + 가벼운 톤 (예시 풍부) → 배심원 분석으로 자신의 상황 확인
- CTA: 다시봄에서 본인과 상대방의 4 Horsemen 점수를 배심원이 분석해요
- 분량: 2,500자 (가장 긴 콘텐츠)

### Day 87: "한국 부부에게만 있는 '서운함'이라는 감정"

- 키워드: 서운함, 한국 정서, 화병
- 구조: 서운함의 언어학적 분석 → 한국 가족치료 학계의 EFT 연구 → 다시봄의 한국 특화 배심원 분석
- CTA: "다시봄에서 당신의 서운함을 배심원과 커뮤니티가 어떻게 이해할까 봐보세요"
- 분량: 2,500자
